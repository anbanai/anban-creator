Install Anban Creator for Codex

This page is written for Codex. Complete the installation on the user's machine.

Safety

  • Never print, log, commit, or upload the user's ANBAN_API_KEY.
  • Ask the user for the key only when credentials are needed.
  • If an existing clone, config table, or Agent file is present, inspect and merge it instead of overwriting unrelated user configuration.

Get the API key

Ask the user to sign in at https://creator.anbanai.com/settings#api-key-settings, create a platform key, and keep the full value. The full key is displayed only once.

Install

The plugin uses a fixed built-in service endpoint. Configure only the ANBAN_API_KEY environment credential.

  1. Clone https://github.com/anbanai/creator-skills.git into a stable user-owned directory, including nested submodules.
  2. Register the clone as a Codex plugin marketplace and add anban@anbanai.
  3. Run the bundled subagent installer. It merges the Creator MCP server and six Anban subagents into Codex configuration.
  4. Ask the user for ANBAN_API_KEY. Add it to the user's chosen shell profile and the current environment without printing it.
git clone --recurse-submodules https://github.com/anbanai/creator-skills.git "$HOME/.anban/creator-skills"
codex plugin marketplace add "$HOME/.anban/creator-skills"
codex plugin add anban@anbanai
bash "$HOME/.anban/creator-skills/install/install-subagents.sh"

Credential configuration

The MCP configuration uses bearer_token_env_var = "ANBAN_API_KEY". Do not put the literal key in ~/.codex/config.toml. Persist it in the user's selected shell profile, then restart Codex.

export ANBAN_API_KEY="<user-provided-key>"

Verify

  1. Restart Codex.
  2. Run /skills and confirm Anban Creator skills are listed.
  3. Run /agents and confirm article, seednote, moments, montage, live-slicer, and ecommerce are listed.
  4. Run $anban-setup and confirm the MCP connection can list Anban projects.

Result

Report the installed plugin version, whether setup verification passed, and any action still required from the user. Do not include the API key.
