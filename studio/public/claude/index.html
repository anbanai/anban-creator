Install Anban Creator for Claude Code

This page is written for Claude Code. Complete the installation on the user's machine.

Safety

  • Never print, log, commit, or upload the user's ANBAN_API_KEY.
  • Ask the user for the key only when Claude Code requests the plugin configuration.
  • If an existing clone or plugin registration is present, inspect and update it instead of deleting unrelated user files.

Get the API key

Ask the user to sign in at https://creator.anbanai.com/settings#api-key-settings, create a platform key, and keep the full value. The full key is displayed only once.

Install

The plugin uses a fixed built-in service endpoint. Configure only the required sensitive api_key in the plugin user config.

  1. Clone https://github.com/anbanai/harness.git into a stable user-owned directory, including nested submodules.
  2. From any directory, register that clone as a Claude Code plugin marketplace.
  3. Install anban@anbanai with user scope.
  4. When Claude Code asks for the required sensitive api_key user configuration, ask the user for ANBAN_API_KEY and enter it without echoing it.
git clone --recurse-submodules https://github.com/anbanai/harness.git "$HOME/.anban/harness"
claude plugin marketplace add "$HOME/.anban/harness"
claude plugin install --scope user anban@anbanai

Verify

  1. Run /anban:anban-setup.
  2. Fully restart Claude Code when setup requests it.
  3. Run /anban:anban-setup again and confirm the MCP connection can list Anban projects.

Result

Report the installed plugin version, whether setup verification passed, and any action still required from the user. Do not include the API key.
