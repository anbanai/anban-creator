# 公众号章节配图生成规范

本文档定义图文文章中章节配图的详细规则，供 `visual-design` skill 按需加载。

## 合规要求

- 配图必须与章节内容**强相关**，从章节具体主题中提炼，禁止通用装饰性描述
- 禁止使用与文章内容无关的装饰性图片

---

## 设计规范

### 1. 整体风格

- 与文章基调匹配的统一风格
- 每篇文章所有章节配图使用同一风格描述

### 2. 文字排版

- 章节配图通常不添加文字（文字由正文处理）
- 信息图类型例外

### 3. 视觉元素

- 包含 2-3 个来自章节的关键词或意象
- 匹配章节的情感基调

### 4. 配图数量参考

| 章节字数 | 建议配图数量 |
|---------|------------|
| < 300 字 | 1 张 |
| 300–600 字 | 1–2 张 |
| > 600 字 | 2–3 张 |

---

## 页面类型要求

按文章基调选择对应风格：

| 文章基调 | 推荐风格 |
|---------|---------|
| [严肃/深度] | 写实摄影风，沉稳深色调，中规中矩构图 |
| [轻松/日常] | 扁平插画，明快色调，简洁构图 |
| [科技/商业] | 简约线条图，低饱和蓝灰配色，现代感 |
| [人文/情感] | 水彩插画，柔和暖色调，留白构图 |
| [美食/生活] | 高清实拍风，暖黄光，近景细节 |

---

## 技术规格

- **比例**：横版（与文章版式匹配）
- **覆盖率**：每个 `##` 章节至少一张
- **位置规则**：关键段落之后，不紧接标题，不放在章节最后一行

---

## 风格一致性

- 在生成第一张配图**之前**，必须先确定全文统一的风格描述
- 所有配图使用同一 `--style` 参数，确保视觉一致性
- 封面图确定后，章节配图风格应与封面基调匹配

---

## Prompt 模板

### 结构公式

```
[章节核心主题] + [具体场景/物体] + [视觉风格] + [构图指导]
```

长度控制在 **30–80 字**。

### 完整模板

```
请生成一张微信公众号文章配图。
章节主题：{section_title}
章节内容摘要：{section_summary}
全文风格：{unified_style}
设计要求：
1. 从章节具体内容中提炼视觉元素
2. 包含 2-3 个来自章节的关键词或意象
3. 匹配章节的情感基调
4. 风格与全文统一（使用 --style 参数）
5. 提示词 30-80 字
```

**变量说明**：

- `{section_title}`：章节标题
- `{section_summary}`：章节核心内容摘要（1-2 句）
- `{unified_style}`：全文统一风格描述

### 禁止用语

以下描述属于通用装饰性语言，**禁止使用**：

- "美丽风景"、"优美画面"
- "抽象背景"、"艺术装饰"
- "相关图片"、"配套插图"
- "科技感图标"（无具体内容指向）

## 好/坏提示词对比

### 示例 1：章节主题"早起习惯对生产力的影响"

| 类型 | 提示词 |
|------|--------|
| 坏 | "美丽的早晨风景" |
| 坏 | "抽象的时间管理背景图" |
| 好 | "清晨5点书桌前，一杯咖啡旁放着计划本，窗外薄雾中透出第一缕阳光，水彩插画风，暖黄色调，俯视视角" |

### 示例 2：章节主题"算法推荐如何影响信息茧房"

| 类型 | 提示词 |
|------|--------|
| 坏 | "科技感的网络图" |
| 好 | "无数信息气泡围绕单个人形，颜色相近的气泡越来越密集，外圈颜色渐渐消失，极简线条插画，蓝灰色调，中心构图" |

### 示例 3：章节主题"断舍离的心理学原理"

| 类型 | 提示词 |
|------|--------|
| 坏 | "整洁的房间图片" |
| 好 | "一双手将杂乱物品整理入收纳盒，周围空白逐渐增多，画面从拥挤过渡到留白，水彩风格，莫兰迪色系，横版构图" |

## CLI 命令

```bash
# 确定统一风格（仅一次）
STYLE="水彩插画，柔和暖色调，留白构图"

# 生成每张章节配图（使用同一风格）
wechatwriter image generate "{section_prompt}" --style "$STYLE"

# 上传到微信素材库
wechatwriter image upload <file_path>

# 批量生成并上传（从 Markdown 提取所有占位符）
wechatwriter image batch article.md --style "$STYLE" -o images.json
```

## 验证清单

在开始批量生成配图前，逐一核查：

- [ ] 已统计文章中所有 `##` 章节数量
- [ ] 每个章节至少有一个配图占位符 `![desc](__generate:prompt__)`
- [ ] 已确定全文统一风格描述（将用于 `--style` 参数）
- [ ] 每个提示词包含该章节的 2 个以上具体关键词
- [ ] 不同章节的提示词有明显差异，体现各章节主题
- [ ] 提示词中包含视觉风格描述，与统一风格一致
- [ ] 提示词长度在 30–80 字之间
