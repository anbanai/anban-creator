# 小红书封面图生成规范

## 封面在三段式中的定位

小红书图文遵循三段式结构，每段服务不同阶段的用户行为：

| 阶段 | 用户行为 | 设计目标 | 核心指标 |
|------|----------|----------|----------|
| **封面** | 信息流里 0.5 秒扫一眼 | 让用户愿意点进来 | 点击率 |
| 中间页 | 已点进来，决定是否看完 | 让用户愿意看完 | 完读率 |
| 尾部页 | 看完了，决定是否互动 | 让用户愿意互动/关注 | 点赞/收藏率 |

**封面的唯一任务：让人点进来。** 所有设计决策都应从这个目标出发推导，而不是死套模板。

### 标题、封面、内容各司其职

三者服务不同的用户行为节点，**不需要讲同一句话**，不要互相对齐：

| 元素 | 优化目标 | 独立策略 |
|------|----------|----------|
| **帖子标题** | 算法推荐 / 搜索发现 | 关键词、好奇缺口、数字钩子 |
| **封面图** | 信息流点击率 | 视觉停留、情绪触发，不必复述标题 |
| **内容图** | 完读率 / 传递实际价值 | 可以比标题/封面承诺的更深、更宽 |

典型案例：封面用无文字高颜值图（视觉钩子），标题走好奇缺口（"90% 的人不知道"），内容老老实实给干货——三者策略完全不同，协同效果反而最好。

**封面不是内容的预告片，也不是标题的图形化**。封面只有一个问题要回答：这张图能让人在 0.5 秒内想点进去吗？

### 从"0.5 秒点击"推导出的设计原则

- **信息密度极低**：0.5 秒只能接收 1 个信号，传递多了反而都传不到。封面只传 1 个足够有吸引力的钩子
- **视觉对比要强**：信息流竞争激烈，必须在视觉上跳出来，高对比度是前提
- **真实感优先**：平台用户对"精致设计感"已产生免疫，真实、粗粝、有颗粒感的内容反而建立信任
- **利益前置**：用户点击的动机是"这对我有用"。钩子必须一眼可见，无论是好奇心、利益感还是情绪共鸣
- **标题视觉权重最高**：如果封面有文字，标题应压过背景、装饰等所有元素——但封面完全可以无文字

## 封面类型

### 0. 笔记风封面（默认推荐）

像随手拍了生活照，然后用荧光笔划线、手写几个字标注分享出来。**不像广告，不像PPT，就是一条普通的笔记**。这是小红书最高点击率的封面形态之一。

**设计要点**：
- 实拍感背景（木桌、绿植、亚麻布、窗边自然光）
- 手写标题或圆润字体，文字≤30%，留白≥50%
- 荧光笔划线或手绘标注点缀
- 单一视觉焦点，莫兰迪大地色系

**适合内容**：种草笔记、知识分享、生活方式、日常干货

### 1. 高颜值美图

一张没有任何配文和装饰的照片，视觉冲击力即核心竞争力。

**设计要点**：颜值即正义（包括脸蛋、穿搭、风景、物品摆放等），视觉冲击力必须强，无需文字覆盖

**适合内容**：美妆教程、穿搭分享、风景摄影、好物推荐

### 2. 图片拼贴

将若干相同主题的图片拼贴，内容丰富多元，有更大概率吸引不同喜好的用户。

**设计要点**：
- 图片风格、色调、氛围相似，整体和谐统一
- 标题不要放在画面角落，字号不可过小，内容主题一目了然

**适合内容**：美食盘点、好物种草、旅游攻略

### 3. 海报大片

精致文艺的封面，有明确标题，类似大片海报风格。

**设计要点**：
- 挑选精美主图，配上主标题、副标题、关键词（正文不宜过长）
- 细节完善，文案简练

**适合内容**：小众好物种草、网红店铺探店

### 4. 对比图

通过巨大反差展现积极的改变，突出产品或方法的效果。

**设计要点**：
- 前后图片的拍摄场景与角度保持一致，体现真实变化
- 配文中点明改变的措施和秘籍，加强冲击感
- 前后对比图不能虚假、夸大、失真

**适合内容**：健身、减肥、塑形、整容、美妆等效果展示

### 5. 纯文字封面

以文字为主，向用户介绍笔记信息概要。

**设计要点**：
- 文字内容必须足够吸引人，标题打开率是核心
- 修饰词避免过于普通；可强调时间、速度、数字、方法论，证明内容有价值
- 字体选择圆润友好，与账号调性一致

**适合内容**：干货分享、硬核教程

### 6. 抠图拼贴

突出强调特定物品或细节，层次分明，视觉感强。

**设计要点**：
- 主次分明，大小有序，错落有致，切忌杂乱堆砌
- 整体色调统一，有明确主色调，避免多种色调混杂

**适合内容**：穿搭分享、好物推荐

### 7. 视频封面

视频笔记的封面需要在静态图中传递动态内容的核心吸引力。三种方式：

- **高冲击帧截取**：从视频中截取最精彩、最具视觉冲击力的单帧，确保画面清晰有张力
- **文字叠加视频帧**：在截帧基础上叠加标题文字，遵循同样的笔记风文字规范（圆润字体、≤30% 占比）
- **自定义设计封面**：独立设计封面图，不使用视频帧，与视频内容主题契合即可

**设计原则**：与图文封面完全相同——笔记感、实拍质感、单一视觉焦点、莫兰迪配色、大量留白。视频标识不影响设计风格判断。

**适合内容**：Vlog、教程类、探店类、才艺展示

## 尺寸选择建议

- **优先竖版 3:4**：占据最大屏幕面积，减少被划走的概率；横版 4:3 屏幕空间小，可能直接被划走
- **多图帖必须统一比例**：上传多张图片时，所有图片必须使用相同比例。系统默认按第一张图的比例对其他图片填充或裁剪，不同比例会丢失重要内容
- **横版图处理方案**：可将横版比例图片嵌入竖版比例相框内发布

---

## 合规要求

- **不要带有任何小红书的 logo**
- **不要有右下角的用户 ID 以及 logo**
- 参考图片中的水印和 logo（尤其是右下角、左上角）必须去掉
- 不要有手机边框或白色留边

## 设计规范

### 1. 整体风格

- **笔记感**取代"设计感"：目标是看起来像真人随手拍照分享，不像广告、PPT、科普海报
- **实拍感为王**：背景必须有真实质感（木桌、亚麻布、绿植、自然光散射），禁止纯色/纯渐变/3D渲染背景
- **朋友语气**：传递"我发现了一个好东西/好方法想跟你分享"的氛围，非专家教导
- 配色使用莫兰迪大地色系，低饱和温润，禁止高饱和/霓虹/深色商务配色

### 2. 封面的内容密度原则

- **信息密度极低**：封面只需传递 1 个钩子（好奇/利益/情绪），不是内容的预告或摘要
- **不要求"信息层级"**：3个信息层级是内容图的要求，封面无此约束
- **文字可有可无**：高颜值封面可以完全无文字；有文字时，标题字号最大，其他元素服从
- **卖点不必写全**：封面不负责传递完整价值，只负责让人"想知道更多"

### 3. 文字排版

- **字体**：圆润手写体或圆润无衬线体；禁止粗黑体、厚重方正体等严肃字体
- **文字占比**：≤30%（大量留白是设计语言，不是设计缺失）
- **高亮方式**：关键词用荧光笔划线效果（粉色/黄色/绿色），贴近手写笔记感
- **标题**：有文字时字号最大，醒目但不沉重（≤15字最佳）；封面完全无文字也是合法选择
- **3秒法则**：陌生人3秒内能看懂这张图想表达什么

**字体-赛道匹配**：

| 内容赛道 | 字体风格 |
|---------|---------|
| 生活/萌宠/美食 | 圆润手写体、可爱感 |
| 教育/职场/金融 | 干净无衬线、专业感 |
| 旅行/自然 | 流畅手写、有机感 |
| 美妆/时尚 | 纤细无衬线、极简感 |
| 科技/3C | 几何无衬线、现代感 |

### 4. 视觉元素

- **实拍感背景**：自然光木质桌面/亚麻布/绿植/白色大理石等，有真实材质和光影细节
- **手绘标注**：手绘箭头、铅笔圆圈、荧光笔划线、贴纸感标签（增加随手笔记感）
- **单一视觉焦点**：一张图只有一个主视觉，其他元素服从主焦点，不抢镜
- **留白呼吸感**：留白≥50%，背景不必填满，大量空白是小红书笔记风的核心美学
- 禁止使用"每一寸空间都承载信息"的PPT式密集排版

### 5. 配色要求

- **主色调**：莫兰迪大地色系
  - 灰豆绿 `#8B9E8B`（主色块/植物感）
  - 奶咖 `#C4A882`（木质/皮革质感区域）
  - 藕粉 `#D4A5A5`（温柔点缀/荧光划线色）
  - 暖米白 `#F5F0EB`（大面积底色/背景基准）
  - 暖深棕 `#5C5147`（正文/标注文字）
- **禁止**：高对比商业色、霓虹色、深色系背景、纯白/纯黑背景

### 6. 禁止清单

- ❌ 3D 渲染物体（廉价感，平台调性不符）
- ❌ 纯色背景（无质感，像PPT幻灯片）
- ❌ 粗黑体/厚重字体（严肃感，与笔记温度不符）
- ❌ 对称PPT布局（过于规整，失去随性笔记感）
- ❌ 科普海报风格（白底+图表+学术排版）
- ❌ 高饱和/霓虹/强对比商业配色
- ❌ 密集文字排版（文字超过30%画面面积）
- ❌ 手机边框或白色留边

---

## 技术规格

- **比例**：竖版 3:4（小红书标准比例）
- **画质**：高清，适合手机屏幕查看
- 所有文字内容必须完整呈现
- 符合正确的竖屏观看排版，不能左右旋转或倒置
- 直接输出图片，无手机边框或白色留边

---

## 风格一致性

- 封面确定的整体色调和设计风格为后续所有内容图的基准
- 所有图片使用同一 `--style` 参数
- `$STYLE` 需在封面生成前确定，结合用户原始需求和完整内容大纲

---

## Prompt 模板

```
请生成一张小红书笔记风格的封面图片。
【合规特别注意的】注意不要带有任何小红书的logo，不要有右下角的用户id以及logo
【合规特别注意的】用户给到的参考图片里如果有水印和logo（尤其是注意右下角，左上角），请一定要去掉
封面钩子：{page_content}
页面类型：封面（唯一任务是让人愿意点进来，不是传递内容）
设计要求：
1. 整体风格：小红书笔记风，像真人随手拍照分享，不像广告/PPT/科普海报，有温度有真实感
2. 实拍感背景（关键）：使用自然光木质桌面/亚麻布/绿植/白色大理石等实拍质感场景，有真实光影和材质细节，禁止纯色/纯渐变/3D渲染背景
3. 配色：莫兰迪大地色系，灰豆绿(#8B9E8B)、奶咖(#C4A882)、藕粉(#D4A5A5)、暖米白(#F5F0EB)，低饱和温润，禁止高对比/霓虹/深色
4. 文字排版：圆润手写体或圆润无衬线体（禁止粗黑体），文字占比≤30%，关键词荧光笔划线高亮，3秒内陌生人能看懂
5. 手绘标注：可添加手绘箭头、铅笔圆圈、荧光笔划线、贴纸感标签，增加随手笔记感
6. 留白呼吸（关键）：留白≥50%，单一视觉焦点，非对称随性构图，不堆砌信息
7. 信息密度：只传递1个钩子信号（好奇/利益/情绪），封面可以完全无文字（纯视觉钩子）
8. 技术规格：竖版 3:4 比例，高清画质
9. 禁止：3D渲染、纯色背景、粗黑体、PPT对称布局、科普海报风、密集文字、手机边框或白色留边
用户原始需求：{user_topic}
请直接给出图片，不要有任何手机边框或白色留边。
```

**变量说明**：

- `{page_content}`：封面的钩子文案（可以是标题、一句话问句、情绪词，或"无文字，纯视觉"）
- `{user_topic}`：用户原始需求/主题描述（用于确定视觉风格，不用于决定封面信息密度）

## CLI 命令

```bash
# 有参考图时（优先）：直接用参考图确定风格
anbanwriter image generate "{prompt}" --post --ref <参考图路径> -o ./cover.png

# 无参考图时：用风格描述（含 hex 色值、背景、字体等完整描述）
STYLE="小红书笔记风，实拍质感背景（自然光木桌/亚麻布），莫兰迪大地色系（灰豆绿#8B9E8B，暖米白#F5F0EB），圆润手写体，手绘荧光划线标注，大量留白≥50%，朋友分享语气"
anbanwriter image generate "{prompt}" --post --style "$STYLE" -o ./cover.png

# 上传到微信素材库
anbanwriter image upload ./cover.png
```
