# 章节配图规范

本文档定义图文文章中章节配图的详细规则，供 `visual-design` skill 按需加载。

## 核心原则

1. **覆盖率**：每个 `##` 章节至少一张配图
2. **相关性**：配图必须与章节内容强相关，从章节具体主题中提炼，不使用通用装饰性描述
3. **风格统一**：同一篇文章所有配图使用同一 `--style` 参数，确保视觉一致性
4. **位置合理**：放在关键段落之后，不紧接 `##` 标题，不放在章节末尾

---

## 风格一致性要求

在生成第一张配图之前，必须先确定全文统一的风格描述，贯穿所有章节。

**风格选择原则**：

| 文章基调 | 推荐风格示例 |
|---------|------------|
| 严肃/深度 | 写实摄影风，沉稳深色调，中规中矩构图 |
| 轻松/日常 | 扁平插画，明快色调，简洁构图 |
| 科技/商业 | 简约线条图，低饱和蓝灰配色，现代感 |
| 人文/情感 | 水彩插画，柔和暖色调，留白构图 |
| 美食/生活 | 高清实拍风，暖黄光，近景细节 |

---

## 配图数量参考

| 章节字数 | 建议配图数量 |
|---------|------------|
| < 300 字 | 1 张 |
| 300–600 字 | 1–2 张 |
| > 600 字 | 2–3 张 |

---

## 配图位置建议

- **首选**：关键论点或转折段落之后
- **次选**：举例说明段落之后
- **避免**：紧接 `##` 标题（视觉跳跃）
- **避免**：放在章节最后一行（结尾感弱化）

---

## 提示词撰写规则

### 结构公式

```
[章节核心主题] + [具体场景/物体] + [视觉风格] + [构图指导]
```

长度控制在 **30–80 字**。

### 关键词来源

必须从章节文本中提炼：
- 章节讨论的核心概念
- 章节提及的具体场景或物体
- 章节的情感基调（振奋/沉思/警示/温暖…）

### 禁止用语

以下描述属于通用装饰性语言，**禁止使用**：

- "美丽风景"、"优美画面"
- "抽象背景"、"艺术装饰"
- "相关图片"、"配套插图"
- "科技感图标"（无具体内容指向）

---

## 好/坏提示词对比

### 示例 1：章节主题为"早起习惯对生产力的影响"

| 类型 | 提示词 |
|------|--------|
| 坏 | "美丽的早晨风景" |
| 坏 | "抽象的时间管理背景图" |
| 好 | "清晨5点书桌前，一杯咖啡旁放着计划本，窗外薄雾中透出第一缕阳光，水彩插画风，暖黄色调，俯视视角" |

### 示例 2：章节主题为"算法推荐如何影响信息茧房"

| 类型 | 提示词 |
|------|--------|
| 坏 | "科技感的网络图" |
| 坏 | "算法相关插图" |
| 好 | "无数信息气泡围绕单个人形，颜色相近的气泡越来越密集，外圈颜色渐渐消失，极简线条插画，蓝灰色调，中心构图" |

### 示例 3：章节主题为"断舍离的心理学原理"

| 类型 | 提示词 |
|------|--------|
| 坏 | "整洁的房间图片" |
| 好 | "一双手将杂乱物品整理入收纳盒，周围空白逐渐增多，画面从拥挤过渡到留白，水彩风格，莫兰迪色系，横版构图" |

## 验证清单

在开始批量生成配图前，逐一核查：

- [ ] 已统计文章中所有 `##` 章节数量
- [ ] 每个章节至少有一个配图占位符 `![desc](__generate:prompt__)`
- [ ] 已确定全文统一风格描述（将用于 `--style` 参数）
- [ ] 每个提示词包含该章节的 2 个以上具体关键词
- [ ] 不同章节的提示词有明显差异，体现各章节主题
- [ ] 提示词中包含视觉风格描述，与统一风格一致
- [ ] 提示词长度在 30–80 字之间
