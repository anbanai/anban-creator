# 小红书内容图生成规范

## 三段式结构：中间页与尾部页的分工

封面之后的图片分为两类，各自服务不同的用户行为阶段：

| 阶段 | 用户状态 | 设计目标 | 核心指标 |
|------|----------|----------|----------|
| 封面 | 信息流扫视，0.5 秒决策 | 让用户点进来 | 点击率 |
| **中间页 `[内容]`** | 已点进来，决定是否看完 | 让用户看完 | 完读率（直接影响推流） |
| **尾部页 `[尾部]`** | 看完了，决定是否互动 | 让用户互动/关注 | 点赞/收藏/关注率 |

### 中间页 `[内容]` 的设计逻辑

**核心目标是完读率**。完读率直接影响平台推流权重，因此中间页的所有设计都应降低用户的"看完成本"：

- **每页只讲一个信息点**：用户没有耐心一次处理多个概念，3 秒能看懂是基准要求
- **视觉引导代替阅读**：用箭头、框选、编号、高亮等视觉元素让信息"被看到"而非"被读到"，降低认知负荷
- **步骤化/结构化优先**：人脑更容易处理有序信息（1/2/3），比散文式排列留存率更高
- **风格连贯性**：与封面视觉语言保持一致，给用户连续的阅读体验，不能"换台"的感觉

### 尾部页 `[尾部]` 的设计逻辑

**核心目标是转化**。用户看完内容后处于"满足感最高点"，是促成互动的最佳时机，也是最脆弱的一刻——一旦引入新信息，价值感会被稀释：

- **不引入新内容**：尾部不是内容页，避免冲淡已建立的价值感
- **提炼记忆点**：用一句话总结全文核心，强化用户"我学到东西了"的感受
- **降低互动门槛**：提问比直接请求更容易引发评论（"你踩过这个坑吗？"比"请评论"有效 10 倍）
- **给出关注理由**：引导关注时要告诉用户"关注了还能获得什么"，而不是空洞的"关注我"
- **排版克制收敛**：视觉上要"收"不要"放"，尾部是收尾而非高潮

## 合规要求

- **不要带有任何小红书的 logo**
- **不要有右下角的用户 ID 以及 logo**
- 参考图片中的水印和 logo（尤其是右下角、左上角）必须去掉
- 不要有手机边框或白色留边
- 风格必须严格参考封面，保持统一

---

## 设计规范

### 1. 整体风格

- 小红书爆款图文风格，清新、精致、有设计感，适合年轻人审美
- 与封面严格统一，使用相同 `$STYLE` 参数

### 2. 内容密度要求（关键）

- **信息丰富度**：每张内容图必须包含可独立阅读的信息密度，不是配图而是内容本体
- **视觉层次**：至少 3 个信息层级（标题/核心内容/辅助说明或数据）
- **文字占比**：图文比例建议 4:6 到 5:5，避免过度留白
- **信息元素**：使用数字标签、图标、高亮色块、进度条、对比表格等增强信息密度
- **行动引导**：适当位置添加互动元素（勾选框 ✅、步骤序号 1️⃣2️⃣3️⃣、对比标签 Before/After）

### 3. 文字排版

- 文字清晰可读，字号适中，重要信息突出显示
- 排版紧凑美观，**留白控制在 20% 以内**
- 所有文字内容必须完整呈现
- 使用项目符号、数字列表、emoji 图标增加可读性

### 4. 视觉元素

- 背景简洁但不单调，可以有装饰性元素
- 配色温暖或清新，保持专业感
- **必须有小图标辅助说明**（如 ✅ ⭐ 📌 💡 等）
- 使用色块、圆角卡片、分割线区分不同信息模块
- 避免纯文字堆砌，视觉元素占 40% 以上

---

## 页面类型要求

### [内容] 类型

- 信息层次分明，列表项清晰展示
- 重点内容用颜色或粗体强调
- 可以有小图标辅助说明

### [尾部] 类型

- 不引入新内容，视觉上"收"而非"放"
- 一句话提炼全文核心记忆点
- 互动引导用提问而非命令（降低门槛）
- 关注引导说明关注后能获得什么（给出理由）
- 可有完成感标志，但不宜夸张

---

## 技术规格

- **比例**：竖版 3:4（小红书标准比例）
- **画质**：高清，适合手机屏幕查看
- 所有文字内容必须完整呈现
- 符合正确的竖屏观看排版，不能左右旋转或倒置
- 直接输出图片，无手机边框或白色留边

---

## 风格一致性

- 必须与封面图保持统一：非封面图统一用 `--ref ./cover.png` 参考封面
- 封面确定了整体色调和设计风格，后续图片通过参考图延续风格
- 严禁与封面风格割裂

---

## Prompt 模板

```
请生成一张小红书风格的图文内容图片。
【合规特别注意的】注意不要带有任何小红书的logo，不要有右下角的用户id以及logo
【合规特别注意的】用户给到的参考图片里如果有水印和logo（尤其是注意右下角，左上角），请一定要去掉
页面内容：{page_content}
页面类型：{page_type}
如果当前页面类型不是封面页的话，你要参考最后一张图片作为封面的样式
后续生成风格要严格参考封面的风格，要保持风格统一。
设计要求：
1. 整体风格：小红书爆款图文风格，清新、精致、有设计感，适合年轻人审美
2. 内容密度（关键）：信息丰富度高，至少3个信息层级，文字占比40%-50%，留白控制在20%以内
3. 文字排版：文字清晰可读，字号适中，重要信息突出显示，使用数字标签/图标/色块区分模块
4. 视觉元素：背景简洁不单调，必须有装饰性元素（图标、色块、分割线），配色温暖或清新
5. [内容]：信息层次分明，列表项清晰展示，重点内容用颜色或粗体强调，每页聚焦一个信息点
6. [尾部]：不引入新内容，一句话提炼记忆点，互动引导用提问句式，排版克制收敛
7. 技术规格：竖版 3:4 比例，高清画质，适合手机屏幕查看，所有文字完整呈现
8. 符合正确的竖屏观看排版，不能左右旋转或倒置
用户原始需求：{user_topic}
完整内容大纲参考：
---
{full_outline}
---
请直接给出图片，不要有任何手机边框或白色留边。
```

**变量说明**：

- `{page_content}`：当前页面的完整文字内容
- `{page_type}`：内容 / 尾部
- `{user_topic}`：用户原始需求/主题描述
- `{full_outline}`：完整内容大纲（可选，有助于风格一致性）

---

## CLI 命令

```bash
# 生成内容图（参考封面保持风格一致）
anbanwriter image generate "{content_prompt}" --post --ref ./cover.png -o ./image_02.png

# 生成尾部图（同样参考封面）
anbanwriter image generate "{tail_prompt}" --post --ref ./cover.png -o ./image_last.png

# 上传到微信素材库
anbanwriter image upload ./image_02.png
```
