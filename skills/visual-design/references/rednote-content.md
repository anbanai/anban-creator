# 小红书内容图生成规范

## 三段式结构：中间页与尾部页的分工

封面之后的图片分为两类，各自服务不同的用户行为阶段：

| 阶段 | 用户状态 | 设计目标 | 核心指标 |
|------|----------|----------|----------|
| 封面 | 信息流扫视，0.5 秒决策 | 让用户点进来 | 点击率 |
| **中间页 `[内容]`** | 已点进来，决定是否看完 | 让用户看完 | 完读率（直接影响推流） |
| **尾部页 `[尾部]`** | 看完了，决定是否互动 | 让用户互动/关注 | 点赞/收藏/关注率 |

### 中间页 `[内容]` 的设计逻辑

**核心目标是完读率**。完读率直接影响平台推流权重，因此中间页的所有设计都应降低用户的"看完成本"：

- **每页讲 2-4 个结构化信息点**：通过编号列表、对比格、步骤流等布局组织，3 秒扫完主信息，10 秒读完全页
- **视觉引导代替阅读**：用箭头、框选、编号、高亮等视觉元素让信息"被看到"而非"被读到"，降低认知负荷
- **步骤化/结构化优先**：人脑更容易处理有序信息（1/2/3），比散文式排列留存率更高
- **风格连贯性**：所有内容图使用组图模式保持风格一致，可使用配置中的参考图或者与封面视觉语言保持一致，给用户最佳的阅读体验，不能产生"换台"的感觉

### 尾部页 `[尾部]` 的设计逻辑

**核心目标是总结留存**。用户看完内容后处于"满足感最高点"，是强化记忆的最佳时机，把全文精华浓缩呈现，让用户带走真正的收获：

- **全文要点汇总**：用3-5条精简条目总结前面所有内容图的核心信息，让用户一眼复盘
- **提炼核心 takeaway**：用一句话总结全文最重要的观点，放在显眼位置强化记忆
- **延续笔记风格**：布局类似"笔记重点回顾"卡片，延续内容图的结构化风格
- **排版克制收敛**：视觉上要"收"不要"放"，尾部是收尾而非高潮

## 合规要求

- **不要带有任何小红书的 logo**
- **不要有右下角的用户 ID 以及 logo**
- 参考图片中的水印和 logo（尤其是右下角、左上角）必须去掉
- 不要有手机边框或白色留边

## 设计规范

### 1. 整体风格

- **延续封面笔记感**：每页都像一张独立的知识笔记，不是PPT幻灯片，不是科普海报
- **结构化知识卡片**：每页用清晰版式承载 2-4 个信息点，像一张精心整理的笔记页
- **朋友分享语气**：用类比代替术语，"就像..."比"即..."有温度，非专家教导
- 与封面严格统一，使用相同 `$STYLE` 参数

### 2. 内容密度要求（关键）

- **文字占比**：35-50%（结构化信息布局，避免无结构文字堆砌）
- **留白**：25-35%，用于分隔信息区块，而非大面积空白
- **每页 2-4 个信息点**：有主次层级，主信息点大字号/色块高亮，用户 3 秒扫完主信息，10 秒读完全页
- **标注增强信息层级**：手绘箭头、圆圈、荧光划线强化结构，而非替代文字
- **阅读节奏**：3 秒看懂主信息点，10 秒读完完整内容

### 3. 结构化布局模式

根据内容类型选择最匹配的布局：

| 布局 | 适用场景 | 信息点数 |
|------|----------|---------|
| 编号清单 | 技巧/要点 | 3-5 条 |
| 对比双栏 | 正误/优劣 | 2-4 组 |
| 步骤流程 | 教程/指南 | 3-4 步 |
| 标注图解 | 拆解/原理 | 3-6 标注 |
| 数据卡片 | 数据/排名 | 2-4 组 |
| 问答配对 | FAQ/误区 | 2-3 组 |

布局原则：区块间用留白或色条分隔、主信息点字号是次要信息的 1.5-2 倍、每个信息点配视觉锚点（编号/图标/色块）、保持统一阅读动线（从上到下/从左到右）。

### 4. 文字排版

- **字体**：圆润友好（圆体/手写体/圆润无衬线体），禁止粗黑体
- **高亮**：关键词用色块填充或荧光笔划线（粉/黄/绿），而非粗体加深
- **紧凑但有节奏**：区块内行间距适中，区块之间留白分隔，信息密度高但不拥挤
- 所有文字内容必须完整呈现

### 5. 视觉元素

- **实拍质感背景**：每页背景与封面保持风格一致，细节丰富，具体场景与内容主题匹配，避免相同背景重复
- **手绘标注**：手绘箭头、铅笔圆圈、荧光笔划线、贴纸感标签，增加手工标注感
- **配色与封面统一**：延续封面确定的色调和氛围，低饱和温润
- **每页构图各异**：主体位置、留白方向、背景场景均不相同，禁止重复视觉元素

### 6. 视觉多样性要求（防止审美疲劳）

- **背景场景轮换**：3张内容图至少用3种不同背景场景，具体场景根据内容主题选择，保持多样性
- **构图角度变化**：上中下/左右/斜对角等多种构图，禁止每页相同
- **主体位置轮换**：文字/焦点物在画面中的位置每页不同（左上/居中/右下等）
- **标注风格多样**：手绘箭头/荧光划线/圆圈标注/贴纸标签，每页搭配不同
- 整体风格统一（色系/调性），但每页视觉构成必须有新意

### 7. 禁止清单

- ❌ 3D 渲染物体（廉价感，与笔记调性不符）
- ❌ 纯色/纯渐变背景（无质感，像PPT幻灯片）
- ❌ 粗黑体/厚重字体（严肃感，失去笔记温度）
- ❌ 死板PPT布局（纯白底+黑字，无笔记质感）
- ❌ 科普海报风格（白底+图表+密集文字+学术排版）
- ❌ 无结构文字堆砌（散文式大段文字，无编号/分区/层级）
- ❌ 重复视觉元素（多张图相同背景/构图/标注方式）
- ❌ 手机边框或白色留边

## 页面类型要求

### [内容] 类型

- 每页围绕一个主题展示 2-4 个结构化信息点，主信息点大字号/色块高亮
- 手绘标注引导视线，用箭头/圆圈/荧光划线强化结构层级
- 关键词色块高亮或荧光划线，而非粗体/下划线

### [尾部] 类型

- 全文要点汇总：用3-5条精简条目总结前面所有内容图的核心信息
- 一句话提炼全文核心 takeaway，放在显眼位置
- 布局风格：类似"笔记重点回顾"卡片，延续内容图的结构化风格
- 视觉上"收"而非"放"，维持笔记感

---

## 技术规格

- **比例**：竖版 3:4（小红书标准比例）
- **画质**：高清，适合手机屏幕查看
- 所有文字内容必须完整呈现
- 符合正确的竖屏观看排版，不能左右旋转或倒置
- 直接输出图片，无手机边框或白色留边

---

## 风格一致性

- 所有内容图必须使用组图模式（`--count`）一次性生成，确保风格完全一致
- 封面确定了整体色调和设计风格，后续内容图延续该风格
- 严禁与封面风格割裂

## CLI 命令

```bash
# 计算内容图总数（封面之外所有页数）
COUNT=<内容图总张数>

# 【必须使用组图模式】一次生成所有内容图（--count 指定张数）
# 输出到目录，自动命名 image_01.png ... image_0N.png
# 禁止逐张调用 image generate
anbanwriter image generate "{unified_content_description}" \
  --count $COUNT \
  --mode xhs -o ./content_images/

# 逐张上传到微信素材库
anbanwriter image upload ./content_images/image_01.png
anbanwriter image upload ./content_images/image_02.png
# ... 依次上传
```

> **注意**：封面图单独生成，内容图必须使用组图模式（`--count`）统一生成，确保风格一致。
