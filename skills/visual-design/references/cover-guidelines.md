# 封面图平台规范

> 来源：微信公众号官方《封面图体验问题案例解析》

## 核心要求

封面图是文章的第一印象，必须满足以下规范，否则影响文章推荐机会。

## 人物展示规范

- **头部五官完整**：人物展示必须保证头部和面部五官完整可见
- **主要人物不可残缺**：多人场景中，主要人物不可被裁切或遮挡导致残缺
- **避免不自然裁切**：构图时注意人物边界，避免在关键部位（头、手、脚）边缘裁切

## 禁止标记和遮挡

禁止在封面图上添加以下元素：

- **马赛克/打码**：对图片内容进行模糊处理
- **视频播放标记**：三角形播放按钮、进度条等视频元素
- **彩色符号标记**：箭头、圆圈、文字框等后期添加的标注符号
- **水印遮挡主体**：大面积水印影响图片主要内容的可读性

## 画质要求

- **清晰度**：禁止使用模糊、虚化、失焦的图片
- **无失真**：多次转载导致压缩失真的图片不可作为封面
- **分辨率**：最低要求 3,686,400 总像素（建议 900x500 或以上）

## 信息含量要求

封面图必须包含有效视觉信息，禁止使用：

- **纯表情包**：无实质内容的表情图片
- **警示标记为主体**：感叹号、停止符等警告图标占据主体
- **纯色无内容图片**：纯色背景无任何视觉元素的图片
- **无关联图片**：与文章内容完全无关的装饰性图片

## 内容相关性

- 封面图必须与文章主旨**高度契合**
- 封面图中的人物/场景应与文章讨论的主题一致
- 若标题提及特定人物，封面图应展示对应人物

## AI 生成封面建议

使用 `wechatwriter image generate` 生成封面时，prompt 应体现：

1. 与文章主题直接相关的场景或元素
2. 清晰的人物/物体，避免模糊效果
3. 不要求添加文字标注（文字由排版层处理）
4. 构图完整，主体居中或符合三分构图法

```bash
# 示例：生成符合规范的封面
wechatwriter image generate "春茶品鉴，一位茶艺师专注点茶，面部表情清晰，背景茶园" -s 2k
```
