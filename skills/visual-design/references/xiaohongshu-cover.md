# 小红书封面图生成规范

## 封面类型

### 1. 高颜值美图

一张没有任何配文和装饰的照片，视觉冲击力即核心竞争力。

**设计要点**：颜值即正义（包括脸蛋、穿搭、风景、物品摆放等），视觉冲击力必须强，无需文字覆盖

**适合内容**：美妆教程、穿搭分享、风景摄影、好物推荐

### 2. 图片拼贴

将若干相同主题的图片拼贴，内容丰富多元，有更大概率吸引不同喜好的用户。

**设计要点**：
- 图片风格、色调、氛围相似，整体和谐统一
- 标题不要放在画面角落，字号不可过小，内容主题一目了然

**适合内容**：美食盘点、好物种草、旅游攻略

### 3. 海报大片

精致文艺的封面，有明确标题，类似大片海报风格。

**设计要点**：
- 挑选精美主图，配上主标题、副标题、关键词（正文不宜过长）
- 细节完善，文案简练

**适合内容**：小众好物种草、网红店铺探店

### 4. 对比图

通过巨大反差展现积极的改变，突出产品或方法的效果。

**设计要点**：
- 前后图片的拍摄场景与角度保持一致，体现真实变化
- 配文中点明改变的措施和秘籍，加强冲击感
- 前后对比图不能虚假、夸大、失真

**适合内容**：健身、减肥、塑形、整容、美妆等效果展示

### 5. 纯文字封面

以文字为主，向用户介绍笔记信息概要。

**设计要点**：
- 文字内容必须足够吸引人，标题打开率是核心
- 修饰词避免过于普通；可强调时间、速度、数字、方法论，证明内容有价值
- 字体选择与账号调性一致

**适合内容**：干货分享、硬核教程

### 6. 抠图拼贴

突出强调特定物品或细节，层次分明，视觉感强。

**设计要点**：
- 主次分明，大小有序，错落有致，切忌杂乱堆砌
- 整体色调统一，有明确主色调，避免多种色调混杂

**适合内容**：穿搭分享、好物推荐

---

## 尺寸选择建议

- **优先竖版 3:4**：占据最大屏幕面积，减少被划走的概率；横版 4:3 屏幕空间小，可能直接被划走
- **多图帖必须统一比例**：上传多张图片时，所有图片必须使用相同比例。系统默认按第一张图的比例对其他图片填充或裁剪，不同比例会丢失重要内容
- **横版图处理方案**：可将横版比例图片嵌入竖版比例相框内发布

---

## 合规要求

- **不要带有任何小红书的 logo**
- **不要有右下角的用户 ID 以及 logo**
- 参考图片中的水印和 logo（尤其是右下角、左上角）必须去掉
- 不要有手机边框或白色留边

---

## 设计规范

### 1. 整体风格

- 小红书爆款图文风格
- 清新、精致、有设计感，适合年轻人审美
- 整体设计要有吸引力和冲击力
- 配色温暖或清新，保持专业感

### 2. 文字排版

- **标题**：占据主要位置，字号最大，醒目大气
- **副标题**：居中或在标题下方
- 文字清晰可读，字号适中

### 3. 视觉元素

- 背景可以更丰富，有视觉焦点，不单调
- 可以有装饰性元素（图标、插画、几何图形）
- 配色温暖或清新

### 4. 配色要求

- 配色和谐，视觉吸引力强
- 与后续内容图风格统一

---

## 技术规格

- **比例**：竖版 3:4（小红书标准比例）
- **画质**：高清，适合手机屏幕查看
- 所有文字内容必须完整呈现
- 符合正确的竖屏观看排版，不能左右旋转或倒置
- 直接输出图片，无手机边框或白色留边

---

## 风格一致性

- 封面确定的整体色调和设计风格为后续所有内容图的基准
- 所有图片使用同一 `--style` 参数
- `$STYLE` 需在封面生成前确定，结合用户原始需求和完整内容大纲

---

## Prompt 模板

```
请生成一张小红书风格的图文封面图片。
【合规特别注意的】注意不要带有任何小红书的logo，不要有右下角的用户id以及logo
【合规特别注意的】用户给到的参考图片里如果有水印和logo（尤其是注意右下角，左上角），请一定要去掉
页面内容：{page_content}
页面类型：封面
设计要求：
1. 整体风格：小红书爆款图文风格，清新、精致、有设计感，适合年轻人审美
2. 文字排版：标题占据主要位置，字号最大，醒目；副标题居中或在标题下方
3. 视觉元素：背景简洁但不单调，可以有装饰性元素，配色温暖或清新
4. 技术规格：竖版 3:4 比例，高清画质
5. 风格一致性：参考用户原始需求确定整体色调和设计风格
用户原始需求：{user_topic}
完整内容大纲参考：
---
{full_outline}
---
请直接给出图片，不要有任何手机边框或白色留边。
```

**变量说明**：

- `{page_content}`：封面的标题、副标题及核心信息
- `{user_topic}`：用户原始需求/主题描述
- `{full_outline}`：完整内容大纲（可选，有助于风格一致性）

---

## CLI 命令

```bash
# 有参考图时（优先）：直接用参考图确定风格
wechatwriter image generate "{prompt}" --post --ref <参考图路径> -o ./cover.png

# 无参考图时：用风格描述（含 hex 色值、背景、边框、字体等完整描述）
STYLE="小红书爆款风，清新精致，莫兰迪配色（主色蓝灰#8B9DAF，米白背景#F5F0EB），圆角卡片，无衬线字体"
wechatwriter image generate "{prompt}" --post --style "$STYLE" -o ./cover.png

# 上传到微信素材库
wechatwriter image upload ./cover.png
```
