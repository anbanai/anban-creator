# 小绿书封面图生成规范

## 合规要求

- **不带微信公众号以外的平台 logo**
- 参考图中的水印/logo 必须去除（尤其注意右下角、左上角）
- 不要有手机边框或白色留边

---

## 设计规范

### 1. 整体风格

- 小绿书爆款图文风格
- 整体设计有吸引力和冲击力
- 配色和谐，视觉吸引力强

### 2. 文字排版

- **标题**：占据主要位置，字号最大，醒目大气
- **副标题**：居中或在标题下方
- 文字清晰可读，排版美观

### 3. 视觉元素

- 背景简洁但有视觉焦点，不单调
- 可以有装饰性元素（图标、插画、几何形状）
- 留白合理，不过于拥挤

### 4. 配色要求

- 配色和谐，温暖或清新
- 与后续内容图风格统一

---

## 技术规格

- **比例**：竖版 3:4
- **尺寸**：`--size 3:4`（默认 2K 档位），使用 `--post` flag
- **画质**：高清，适合手机屏幕查看
- **输出**：直接输出图片，无手机边框或白色留边

---

## 风格一致性

- 封面确定的配色、设计风格、排版布局为后续所有内容图的基准
- 所有图片使用同一 `--style` 参数
- `$STYLE` 需在封面生成前确定，贯穿整套图文

---

## Prompt 模板

```
请生成一张微信小绿书封面图片。
页面内容：{page_content}
设计要求：
1. 标题占据主要位置，字号最大，醒目大气
2. 副标题居中或在标题下方
3. 背景简洁但有视觉焦点
4. 配色和谐，视觉吸引力强
5. 竖版 3:4 比例
6. 文字清晰可读，排版美观
7. 可以有装饰性元素（图标、插画）
```

**变量说明**：

- `{page_content}`：封面的标题、副标题及核心信息

---

## CLI 命令

```bash
# 确定统一风格
STYLE="扁平信息图，低饱和莫兰迪配色，圆角卡片，无衬线字体"

# 生成封面图
wechatwriter image generate "封面：{title}" --post --style "$STYLE" -o ./cover.png

# 上传到微信素材库
wechatwriter image upload ./cover.png
```
