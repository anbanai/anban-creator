# 公众号封面图生成规范

> 来源：微信公众号官方《封面图体验问题案例解析》

## 合规要求

### 人物展示规范

- **头部五官完整**：人物展示必须保证头部和面部五官完整可见
- **主要人物不可残缺**：多人场景中，主要人物不可被裁切或遮挡导致残缺
- **避免不自然裁切**：构图时注意人物边界，避免在关键部位（头、手、脚）边缘裁切

### 禁止标记和遮挡

禁止在封面图上添加以下元素：

- **马赛克/打码**：对图片内容进行模糊处理
- **视频播放标记**：三角形播放按钮、进度条等视频元素
- **彩色符号标记**：箭头、圆圈、文字框等后期添加的标注符号
- **水印遮挡主体**：大面积水印影响图片主要内容的可读性

### 信息含量要求

封面图必须包含有效视觉信息，禁止使用：

- **纯表情包**：无实质内容的表情图片
- **警示标记为主体**：感叹号、停止符等警告图标占据主体
- **纯色无内容图片**：纯色背景无任何视觉元素的图片
- **无关联图片**：与文章内容完全无关的装饰性图片

---

## 设计规范

### 1. 整体风格

- 横版构图，视觉冲击力强
- 与文章主旨高度契合，一眼识别核心内容
- 封面图中的人物/场景应与文章讨论的主题一致
- 若标题提及特定人物，封面图应展示对应人物

### 2. 文字排版

- 不要求添加文字标注（文字由排版层处理）
- 若需添加标题文字，确保字体清晰可读

### 3. 视觉元素

- 清晰的人物/物体，避免模糊效果
- 构图完整，主体居中或符合三分构图法
- 色彩鲜明，视觉冲击力强

### 4. 配色要求

- RGB 色彩模式，避免 CMYK
- 色彩与文章基调匹配

---

## 技术规格

- **比例**：横版 16:9
- **尺寸**：`--size 16:9`（默认 2K 档位），最低总像素 ≥3,686,400
- **画质**：高清，无失真，禁止使用模糊/虚化/失焦图片，多次转载压缩失真的图片不可使用
- **格式**：JPG、PNG
- **色彩模式**：RGB

---

## 风格一致性

- 封面图确定后，其风格应为后续章节配图提供基调参考
- 多篇文章系列时，使用 `--style` 参数保持封面视觉统一

---

## Prompt 模板

```
请生成一张微信公众号文章封面图。
页面内容：{article_title}
设计要求：
1. 横版 16:9 构图
2. 与文章主题直接相关的场景或元素
3. 清晰的人物/物体，避免模糊效果
4. 不添加文字标注
5. 构图完整，主体居中或三分构图法
6. 色彩鲜明，视觉冲击力强
```

**变量说明**：

- `{article_title}`：文章标题或核心主题

---

## CLI 命令

```bash
# 生成封面图（2K 高清，横版 16:9）
anbanwriter image generate "{prompt}" -s 2k

# 示例：生成符合规范的封面
anbanwriter image generate "春茶品鉴，一位茶艺师专注点茶，面部表情清晰，背景茶园" -s 2k

# 上传到微信素材库
anbanwriter image upload ./cover.png
```
