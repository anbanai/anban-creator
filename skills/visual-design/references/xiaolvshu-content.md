# 小绿书内容图生成规范

## 合规要求

- **不带微信公众号以外的平台 logo**
- 参考图中的水印/logo 必须去除（尤其注意右下角、左上角）
- 不要有手机边框或白色留边
- 风格必须严格参考封面，保持统一

---

## 设计规范

### 1. 整体风格

- 与封面严格统一，使用相同 `$STYLE` 参数
- 小绿书爆款图文风格，信息清晰

### 2. 文字排版

- 文字完整呈现，不截断
- 重点内容用颜色或粗体强调
- 排版美观，留白合理

### 3. 视觉元素

- 支持 emoji 和符号辅助表达
- 小图标辅助说明，增强可读性
- 信息层次分明

---

## 页面类型要求

### [内容] 类型

- 信息层次分明，列表项清晰展示
- 重点内容用颜色或粗体强调
- 可以有小图标辅助说明

### [总结] 类型

- 总结性文字突出
- 可有勾选框/完成标志
- 给人完成感，可加鼓励性视觉元素

---

## 技术规格

- **比例**：竖版 3:4
- **尺寸**：`--size 3:4`（默认 2K 档位），使用 `--post` flag
- **风格**：所有图使用同一 `--style` 参数（与封面一致）
- **输出**：直接输出图片，无手机边框或白色留边

---

## 风格一致性

- 必须与封面图使用同一 `$STYLE` 参数
- 配色、设计风格、排版布局严格参考封面
- 生成前先确认封面 `$STYLE` 值

---

## Prompt 模板

```
请生成一张微信小绿书内容图片。
页面内容：{page_content}
页面类型：{page_type}（内容/总结）
参考封面风格：参考封面的配色、设计风格、排版布局
设计要求：
1. 信息层次分明，列表项清晰展示
2. 重点内容用颜色或粗体强调
3. 可以有小图标辅助说明
4. 排版美观，留白合理
5. 风格与封面严格统一
6. 竖版 3:4 比例
7. [如为总结] 总结性文字突出，有完成感
```

**变量说明**：

- `{page_content}`：当前页面的完整文字内容
- `{page_type}`：内容 / 总结

---

## CLI 命令

```bash
# 生成内容图（使用与封面相同的 $STYLE）
wechatwriter image generate "内容：{content}" --post --style "$STYLE" -o ./image_02.png

# 生成总结图
wechatwriter image generate "总结：{summary}" --post --style "$STYLE" -o ./image_last.png

# 上传到微信素材库
wechatwriter image upload ./image_02.png
```
