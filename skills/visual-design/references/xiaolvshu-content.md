# 小绿书内容图生成规范

## 三段式结构：中间页与尾部页的分工

封面之后的图片分为两类，各自服务不同的用户行为阶段：

| 阶段 | 用户状态 | 设计目标 | 核心指标 |
|------|----------|----------|----------|
| 封面 | 信息流扫视，0.5 秒决策 | 让用户点进来 | 点击率 |
| **中间页 `[内容]`** | 已点进来，决定是否看完 | 让用户看完 | 完读率（直接影响推流） |
| **尾部页 `[尾部]`** | 看完了，决定是否互动 | 让用户互动/关注 | 点赞/收藏/关注率 |

### 中间页 `[内容]` 的设计逻辑

**核心目标是完读率**。完读率直接影响平台推流权重，因此中间页的所有设计都应降低用户的"看完成本"：

- **每页只讲一个信息点**：用户没有耐心一次处理多个概念，3 秒能看懂是基准要求
- **视觉引导代替阅读**：用箭头、框选、编号、高亮等视觉元素让信息"被看到"而非"被读到"，降低认知负荷
- **步骤化/结构化优先**：人脑更容易处理有序信息（1/2/3），比散文式排列留存率更高
- **风格连贯性**：与封面视觉语言保持一致，给用户连续的阅读体验

### 尾部页 `[尾部]` 的设计逻辑

**核心目标是转化**。用户看完内容后处于"满足感最高点"，是促成互动的最佳时机：

- **不引入新内容**：尾部不是内容页，避免冲淡已建立的价值感
- **提炼记忆点**：用一句话总结全文核心，强化用户"我学到东西了"的感受
- **降低互动门槛**：提问比直接请求更容易引发评论（"你踩过这个坑吗？"比"请评论"有效 10 倍）
- **给出关注理由**：引导关注时要告诉用户"关注了还能获得什么"，而不是空洞的"关注我"
- **排版克制收敛**：视觉上要"收"不要"放"，尾部是收尾而非高潮

---

## 合规要求

- **不带微信公众号以外的平台 logo**
- 参考图中的水印/logo 必须去除（尤其注意右下角、左上角）
- 不要有手机边框或白色留边
- 风格必须严格参考封面，保持统一

---

## 设计规范

### 1. 整体风格

- 与封面严格统一，使用相同 `$STYLE` 参数
- 小绿书爆款图文风格，信息清晰

### 2. 文字排版

- 文字完整呈现，不截断
- 重点内容用颜色或粗体强调
- 排版美观，留白合理

### 3. 视觉元素

- 支持 emoji 和符号辅助表达
- 小图标辅助说明，增强可读性
- 信息层次分明

---

## 页面类型要求

### [内容] 类型

- 信息层次分明，列表项清晰展示
- 重点内容用颜色或粗体强调
- 可以有小图标辅助说明

### [尾部] 类型

- 不引入新内容，视觉上"收"而非"放"
- 一句话提炼全文核心记忆点
- 互动引导用提问而非命令（降低门槛）
- 关注引导说明关注后能获得什么（给出理由）
- 可有完成感标志，但不宜夸张

---

## 技术规格

- **比例**：竖版 3:4
- **尺寸**：`--size 3:4`（默认 2K 档位），使用 `--post` flag
- **风格**：所有图使用同一 `--style` 参数（与封面一致）
- **输出**：直接输出图片，无手机边框或白色留边

---

## 风格一致性

- 必须与封面图使用同一 `$STYLE` 参数
- 配色、设计风格、排版布局严格参考封面
- 生成前先确认封面 `$STYLE` 值

## Prompt 模板

### 视觉丰富化原则

| 维度 | 说明 | 示例写法 |
|------|------|---------|
| 背景氛围 | 背景不能只是纯色，要有质感或微妙渐变 | 细纹亚麻布纹、米白水彩晕染底、磨砂毛玻璃质感 |
| 装饰元素 | 添加锚定视觉的装饰性细节 | 右下角小植物插画、左侧彩色竖条、标题下的手绘下划线 |
| 色彩层次 | 至少 3 层色彩（底色、主色、点缀色） | 米白底 + 莫兰迪绿主色块 + 金色小标签点缀 |
| 材质暗示 | 图片元素有具体材质感 | 卡片有投影感和圆角、文字区有轻微纸张纹理 |
| 空间纵深 | 通过元素大小差异营造层次感 | 背景大区域底色 + 中景卡片 + 前景重点数字 |

```
请生成一张微信小绿书内容图片。
页面内容：{page_content}
页面类型：{page_type}（内容/尾部）
参考封面风格：参考封面的配色、设计风格、排版布局
设计要求：
1. 信息层次分明，列表项清晰展示
2. 重点内容用颜色或粗体强调
3. 可以有小图标辅助说明
4. 排版美观，留白合理
5. 风格与封面严格统一
6. 竖版 3:4 比例
7. [如为尾部] 一句话记忆点提炼，提问式互动引导，排版克制收敛
视觉丰富化要求：
- 背景质感：不要纯色背景，使用细纹纸质/布纹/水彩晕染等质感底色
- 卡片投影：信息卡片加轻微投影和圆角（约 8-12px），营造立体感
- 装饰锚点：至少 1 个装饰性元素（植物插画/手绘线条/图标角标）
- 色彩分层：底色 + 主色块 + 点缀色，至少 3 层色彩层次
- 关键词特殊处理：数字/关键词用特殊字体或色块高亮，不能等比普通文字
```

**变量说明**：

- `{page_content}`：当前页面的完整文字内容
- `{page_type}`：内容 / 尾部

## CLI 命令

```bash
# 计算内容图总数（封面之外所有页数）
COUNT=<内容图总张数>

# 【必须使用组图模式】一次生成所有内容图（--count 指定张数）
# 输出到目录，自动命名 image_01.png ... image_0N.png
# 禁止逐张调用 image generate
anbanwriter image generate "{unified_content_description}" \
  --count $COUNT \
  --mode xls --style "$STYLE" -o ./content_images/

# 逐张上传到微信素材库
anbanwriter image upload ./content_images/image_01.png
anbanwriter image upload ./content_images/image_02.png
# ... 依次上传
```

> **注意**：封面图单独生成（`image generate ... -o ./cover.png`），内容图使用组图模式统一生成，确保风格一致。
