# Rednote Viral Copy 链路

目标：输入一条爆款笔记 ID 或 URL，输出"高贴合主题"的可发布新笔记（封面/配图、标题、正文、话题）。

## 标准流程

1. 获取爆款笔记完整内容
2. 拆解爆款因素（标题/封面/正文/互动）
3. 改写生成新内容
4. 使用 `anbanwriter image generate` 生成图片
5. 用 MCP `publish_post` 发布

## 1) 输入

- `post_id`：爆款笔记 ID（从 URL 提取）
- `copy_mode`：`style-only`（默认）| `tight`（高一致性）| `medium`（中贴合）

默认使用 `style-only`：保留原主题与互动机制，封面只参考风格/色调/信息层级，不复用具体元素。

## 2) 获取源笔记

使用 MCP 工具获取笔记详情：

```
get_feed_detail(post_id="<爆款笔记ID>")
```

提取并记录：
- **标题模板**：年份/动作词/情绪词/句式
- **封面模板**：主文案、信息层级、配色、字体大小
- **正文模板**：开场金句、段落数量、结尾 CTA
- **互动模板**：评论区高频动作词、参与门槛
- **标签模板**：核心话题 + 长尾话题

输出 `Source Template`（简短结构化记录）。

## 3) Viral Copy 改写规则

**tight 模式**（高一致性）：

- 保留：同主题、同互动机制（如"评论区打确认"）、同内容结构
- 替换：具体措辞、案例细节、账号人设口吻
- 禁止：逐句照抄、原图二次使用、原作者专属信息

**style-only 模式**（默认）：

- 封面：仅参考风格、色调、信息分层与竖版构图
- 明确禁止复用：人物姿势、图标组合、文本框形状与位置
- 使用"保留主题 + 重设计元素"策略

## 4) 输出格式

1. **标题**：内部生成 3 个候选，使用爆款因子评分自动选 Top 1（≤20 字）：
   ```
   title_score = 情绪强度(0-3) + 关键词密度(0-1) + 字数优化(0-1) + 句式加分(0-1)
   情绪强度: 含强情绪词→3, 中情绪→2, 弱情绪→1, 无→0
   字数优化: 12-18字→1, 否则→0
   句式加分: 疑问/否定/数字句式→1, 否则→0
   ```
2. **正文**：1 版可直接发布（含话题标签）
3. **图片提示词**：
   - 封面：主文案 + 副文案 + 1 条生图 prompt
   - 配图：3-6 张图解文案 + 对应 prompt
4. **话题**：5-8 个

## 5) 图片生成

```bash
# 生成封面图
anbanwriter image generate "<封面prompt>" --post --style "$STYLE" -o ./cover.png

# 生成配图
anbanwriter image generate "<内容prompt>" --post --style "$STYLE" -o ./image_02.png
```

## 6) 发布

合规检查通过后直接发布，无需等待用户确认：

```
publish_post(
  title="<评分选定的标题>",
  content="<正文+话题标签>",
  images=["./cover.png", "./image_02.png"],
  tags=["话题1", "话题2", "话题3"]
)
```

发布失败时指数退避重试（5s → 15s → 30s），3 次仍失败则保存至 `$DIR/publish-failed.json`。

## 7) 合规检查（自动化执行）

加载 [prohibited-words.md](references/prohibited-words.md) 违禁词库，扫描标题与正文：

- **高风险词**：删除所在句子或重写段落，超过 3 处触发全文重写
- **中风险词**：自动替换为合规近义词
- **低风险词**：自动替换或删除

生成 `$DIR/compliance-report.md` 记录所有修改。所有检查通过后方可发布。
