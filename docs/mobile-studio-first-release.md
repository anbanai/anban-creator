# 手机创作工作台首版

基线：main `4987535`。分支：`feature/mobile-creation-studio`。
只提交 PR，合伙人审核后决定合并和发布。

## 已实现

- 登录沿用现有账号和认证接口。手机登录后进入简化工作台，桌面首页保持原有助手入口。
- 手机底部四入口：创作、人设、作品、我的。现有更多功能保留在顶部菜单。
- 对话建立新人设、查看与继续完善已保存人设；独立的新建意图防止复用上一位人设会话，并在首次进入后消费，刷新可恢复现有会话。
- 公众号文章、小红书图文进入现有助手，携带当前人设、准确的内容类型和可编辑需求，确认后才生成。
- 短视频剪辑进入现有素材剪辑表单，保留需求，再上传素材和确认设置。
- 电商图片提供主图、详情图、白底图、SKU 图入口。选择映射到已有的 `selected_modules` 和需求文本，不新增生成模型或模块；白底图使用主图模块加明确的纯白背景要求。
- 人设未启用相应创作类型时显示现有设置弹窗，由用户确认后保存，避免进入错误类型。电商当前仍为独立配置，切换前明确说明会替换原创作类型、保留画像。
- 复用作品列表、最终交付预览、分享与下载；手机详情将辅助人设/参数默认折叠。
- 手机回车换行、显式按钮发送；输入区响应可见视口和键盘，加入安全区留白；登录与主要输入字号适配手机。

## 架构与发布

所有 `/mobile/*` 页面处于既有登录保护内。共用 Project、Task、图片模块、账单、服务端鉴权与结果，不引入第二套后端、数据库或权限。
新增页面和移动交互集中在 Studio；只需构建/更新 Studio 镜像。不存在新增 API key 或生产配置。

入口：`/mobile`（手机首页），`/mobile/personas`（人设），`/mobile/create`（内容入口），`/mobile/account`（我的）。手机访问 `/` 无显式对话上下文时显示手机首页；带对话上下文时进入现有助手。
