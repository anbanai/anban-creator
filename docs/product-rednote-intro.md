# 案板智能创作助手 — 小红书功能介绍

## 产品简介

案板智能创作助手是一款 AI 驱动的小红书内容创作工具。你只需提供一个主题或一篇对标笔记，系统会自动完成从选题研究到图文生成的全部工作——包括选题分析、文案撰写、标题优化、话题标签、封面设计、内容配图和尾图。

**一句话概括：给定主题，一键输出完整的小红书图文笔记。**

> 📷 **截图需求**：产品整体界面截图，展示管理后台的任务列表或首页概览，让客户对产品有第一印象

## 核心功能

### 1. 选题研究

不需要自己刷小红书找灵感。系统自动采集你所在领域的热门笔记，分析每篇笔记的互动数据（点赞、收藏、评论），并通过评分模型为潜在选题打分。

- **数据驱动**：评论权重是点赞的 2 倍——因为评论代表深度互动，是爆款的真正信号
- **时效筛选**：24 小时内发布的内容权重最高，超过 30 天的自动降权——筛选的是"什么正在火"，而非"什么火过"
- **新颖度加成**：被同类笔记覆盖少于 3 篇的角度自动获得加分

> 📷 **截图需求**：选题分析结果截图，展示评分排名、互动数据对比、选中理由等内容（对应 `topic-analysis.md` 的输出效果）

### 2. 内容创作

系统根据选题自动生成完整的笔记内容，包括标题、正文和话题标签。

- **标题优化**：自动生成多个候选标题并评分（情绪强度、关键词密度、句式加分），选最优。标题控制在 20 字以内，关键词前置
- **风格适配**：根据目标受众自动调整文案风格——面向年轻女性用轻松语态 + emoji，面向 30+ 人群用品质叙事，面向专业人士用数据支撑
- **标签策略**：从核心话题、垂直领域、长尾话题三个层级自动搭配 5-8 个标签，覆盖更广流量
- **格式适配**：自动将 Markdown 格式转换为小红书兼容的 emoji 标记和符号排版

> 📷 **截图需求**：AI 生成的笔记内容效果截图，展示标题、正文排版、话题标签的最终效果

### 3. 封面设计

自动生成 3:4 竖版封面图，适配小红书的展示比例。

- 根据笔记主题、目标受众和账号定位动态设计
- 封面确立整篇笔记的视觉风格基准，后续内容图以此为参考保持一致

> 📷 **截图需求**：2-3 张不同主题的 AI 生成封面图示例（3:4 竖版），风格差异明显

### 4. 内容配图

将正文中的关键信息拆解为知识可视化图片，批量生成、风格统一。

- **信息密度控制**：每张图不超过 3 个核心信息点
- **布局自动适配**：对比类用左右分栏，步骤类用流程线，总结类用卡片式
- **奇数页策略**：图片总数调整为奇数，利用用户"翻完最后一页"的习惯，提升尾图触达率
- **风格一致性**：所有内容图以封面为风格参考，同色系、同排版风格

> 📷 **截图需求**：一组完整的内容配图系列（3-5 张），展示风格统一的知识可视化图片

### 5. 尾图设计

根据内容类型自动选择尾图策略，最大化最后一页的价值。

| 内容类型 | 尾图策略 |
|---------|---------|
| 知识分享 | 总结型信息图，浓缩核心知识点 |
| 测评对比 | 评分表或对比图，便于截图分享 |
| 好物种草 | 产品集合图或优惠信息，引导转化 |

尾图遵循小红书平台规范，不包含违规的诱导互动表述。

> 📷 **截图需求**：三种不同类型尾图的示例（知识总结型、评分对比型、好物推荐型）

## 创作模式

### 原创模式

提供主题即可。系统自动完成：选题研究 → 内容创作 → 图片生成 → 合规检查。

```
输入：降噪耳机种草笔记
输出：完整笔记（文案 + 封面 + 内容图 + 尾图 + 话题标签）
```

### 复刻模式

提供一篇对标笔记的链接或 ID，系统分析源笔记的模板结构（内容框架、视觉风格、图片张数），然后基于你的账号定位进行改写和重新设计。

支持三种改写程度：

- **轻度改写**（style）：保留信息点，替换表达方式和视觉风格
- **中度改写**（medium）：保留核心观点，重新组织结构和内容
- **深度改写**（tight）：仅保留方向，完全重新创作

> 📷 **截图需求**：复刻模式的效果对比——左边是源笔记截图，右边是 AI 改写后的笔记截图，体现"同题不同作"的能力

## 质量保障

- **违禁词检查**：自动扫描标题和正文，识别并标记小红书平台违禁词汇
- **诱导互动合规**：自动清除"评论区"、"点赞收藏"、"关注送"等违规引导语，避免限流
- **视觉一致性**：所有图片（封面 + 内容图 + 尾图）保持统一的视觉风格
- **平台适配**：图片比例、字数限制、标签格式均严格适配小红书规范

## 业务场景案例

### 场景一：电商品牌日常种草

**行业**：消费电子 / **账号**：品牌官方号

品牌每周需要发布 3-5 篇小红书种草笔记，覆盖不同产品线和卖点。传统模式下需要文案 + 设计师配合，单篇耗时 2-3 小时。

使用案板后：运营人员只需提交产品主题（如"蓝牙音箱 户外露营"），系统自动完成选题分析、种草文案、产品配图全套输出。**单篇创作时间从 2-3 小时缩短到 5 分钟审核时间。**

> 📷 **截图需求**：一篇完整的产品种草笔记在小红书上的发布效果截图（含互动数据）

### 场景二：MCN 机构批量内容生产

**行业**：MCN / **账号**：多矩阵号

MCN 同时运营多个垂直领域账号，需要持续输出不同风格的内容。传统模式下内容同质化严重，且人力成本随账号数量线性增长。

使用案板后：每个账号配置独立的定位和风格，系统根据账号画像自动适配文案语态和视觉风格。**支持一人管理 10+ 账号的日常更新，产出效率提升 5 倍以上。**

> 📷 **截图需求**：管理后台中多个不同账号/频道的任务列表截图，展示批量管理能力

### 场景三：个人博主爆款复刻

**行业**：美妆 / 生活方式 / **账号**：个人号

新手博主看到同领域爆款笔记，想借鉴思路但不想照搬。传统方式需要手动拆解对标笔记的结构，再重新创作，效率低且容易过度模仿。

使用案板后：粘贴对标笔记链接，系统自动分析其内容框架和视觉结构，然后基于博主自身定位进行改写。**三种改写深度可选，既保留爆款逻辑又保持原创性。**

> 📷 **截图需求**：复刻模式的输入界面截图（粘贴链接/选择改写程度）+ 输出效果

### 场景四：知识付费内容引流

**行业**：教育培训 / **账号**：讲师个人号

知识类博主需要持续输出专业内容吸引粉丝，但专业内容的可视化制作门槛高——需要把抽象知识点变成信息图、流程图、对比图。

使用案板后：系统自动将知识点拆解为 2-3 个一组的信息图，每张图信息密度可控，布局自动适配。**知识类笔记的收藏率显著提升，因为读者"一眼能看懂，随时能回顾"。**

> 📷 **截图需求**：一组知识类内容配图示例（信息图/流程图/对比图），突出知识可视化效果
