## 使用

用户已选择连接现有线上案板账号。这是**真实线上读写**，不是 Mock。

在 `studio` 启动 `bun run dev -- --config preview.online.config.ts`；需要离线语音时沿用 `ANBAN_PREVIEW_WHISPER_ROOT`。本机登录地址 `http://127.0.0.1:5175/login`，通用空白入口 `http://127.0.0.1:5175/onboarding-online.html`。

专用配置固定监听回环地址5175，通过 HTTPS 转接 `https://creator.anbanai.com` 的 `/api` 与 `/ws`，保留证书校验。实测旧 `api.creator.anbanai.com` 入口返回503，官网入口正常。本次未改生产环境配置。普通5173、离线预览5174不切到线上。HMR 在5175关闭，避免开发时重置正在编辑的对话；代码更新后手动刷新。

用户在现有 Studio 登录界面登录；不提取、打印或复制登录凭据。浏览器使用现有认证/刷新流程，DeepSeek 密钥仍只在本机服务端。

## 实际链路

1. 对话生成候选 → 用户确认当前画像。
2. 点击保存，调用现有 `POST /projects`，保留真实项目编号。
3. 读取现有画像版本，调用 `PUT /projects/:id/profile`。六维映射保持原契约，`experience` 转入 `memory`，本次选题不写入长期画像。
4. 展示服务端可用执行档位、任务启动费用与钱包余额，选择公众号文章或小红书图文。
5. 点击生成前再次核对登录用户、画像版本、费用和余额。公众号任务还检查当前项目是否配置公众号 AppID，缺失时停在提交前，提示从项目「渠道配置」绑定；密钥被 Server 脱敏，因此这不等于验证密钥有效或微信权限完整。通过现有 task-form 请求映射创建**一项**真实任务。
6. 展示真实任务编号，轮询任务状态，跳转已有任务详情查看进度、文件和作品。任务结束、正文交付、发布结果保持区别；不调用公开发布接口，也不自动重试付费任务。

任务价格只是启动费用，图片等后续操作依线上规则计费。模型来源由线上执行档位决定，DeepSeek 仅用于当前定位访谈。

## 恢复与并发边界

- 本机 sessionStorage 只存恢复回执（用户、画像比对信息、项目/任务编号及已知版本），项目、画像版本和任务状态仍以 Server 为准。
- 每个写入步骤先记录进度；网络中断后若不知道是否已创建，不自动重发以免重复项目或重复扣费。可从真实项目/任务列表核对；没有引入伪造幂等保证。
- 画像确认响应丢失后，可以读取 Server 当前版本及内容确认是否已经保存。新旧版本冲突、切换账号、画像变化时停止覆盖。
- 页面关闭时已发出的写请求仍可能完成；回执保留其项目编号。离开页面不代表取消线上任务。
- 临时恢复入口可以从本机备份恢复对话和带依据的候选；仍校验全部引用，且不恢复“已确认”标志，不自动写入线上。客户资料和临时恢复入口都在忽略目录，不进入 Git。通用入口从空白开始。
- 对话草稿仍不是跨设备持久化；保存后的项目和任务可在正式账号中读取。

## 2026-10-10：访谈进度与结果优先

- 访谈区固定展示六项信息的收集进度、百分比和已知/未知项目；百分比只代表信息覆盖，不表示定位准确率，也不按聊天轮数计时。身份、受众、平台满足原有确认规则后，直接显示“已足够开始，可以结束访谈了”，提供就近的确认入口。其他信息可后补，不要求达到100%。未发送修正、录音与请求期间仍阻止确认。

- 完成任务的创作过程默认折叠；进行中和失败任务仍展开以便处理。配图和其他交付文件也可展开查看。公众号端受阻或待核实与内容生成完成分别说明，不自动发布或重试。
- 不改变数据库、任务计费、发布权限、文件状态或服务端交付判定。原始文件和日志保留。真实任务已经验证一键打开最终文章。
