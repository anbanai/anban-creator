# Anban 产品定位

## 定位

Anban 是面向自媒体与品牌内容团队的内容生成操作系统。

## 核心承诺

从选题判断、内容与素材生成，到发布数据回流和效果复盘，帮助团队持续产出高质量内容并改进下一轮创作。

## 用户与问题

Anban 服务需要持续运营一个或多个品牌、创作者或平台账号的个人与团队。他们需要稳定地产出符合账号定位的内容，也需要把选题、生产、发布记录和效果观察连起来，避免每次创作都从零开始。

## 闭环

1. 沉淀品牌或账号定位、受众、风格和素材。
2. 发现趋势并判断选题与账号方向的匹配度。
3. 使用 Agent 工作流生成内容、视觉素材和交付物。
4. 管理作品进度、排期和可用的发布状态。
5. 回收或导入内容表现数据，比较内容与账号表现。
6. 复盘效果，把经过验证的经验带回后续创作决策。

## 表达边界

- 可以说 Anban 将内容生产和数据复盘连接起来，并以数据支持后续选题与创作。
- 不承诺每个平台都已具备自动发布或完整的数据回传能力；可用能力取决于平台接入与项目配置。
- 单条归因洞察只是候选结论。它需要用户确认，并由独立的后续分析版本验证。
- AI 负责内容生成和辅助分析；发布策略、持久化业务状态与外部发布动作由 Server 管理。

## 对外表达

**一句话**：从选题到复盘，让每一轮内容生产都成为下一轮的依据。

**解释句**：Anban 把项目画像、趋势研究、AI 内容生产、发布记录和表现分析放在同一个工作空间，帮助自媒体与品牌内容团队持续生产并改进内容。
