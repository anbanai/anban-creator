# 首页人设创作类型设置

基于 `main` 的 `68bfeec` 开发，功能分支 `feature/home-creation-type`。

## 用户流程

- 选择尚未配置创作类型的人设，首页显示「还未选择创作类型」，并提供「选择创作类型」。
- 使用现有类型选择弹窗，可多选；保存后留在首页，保留输入内容。保存只更新设置，不创建作品。
- 首页可用类型显示在「本次创作」下拉框中；可以继续调整已选类型。
- 首页对话暂不支持或不匹配主平台的已选类型，提供「前往创作页」，并携带当前人设 ID。
- 取消不保存；失败留在弹窗中显示错误，可重试。

## 技术边界

- 仅 Studio 与文档；复用 `PUT /projects/:id`，无服务端、数据库、Harness、密钥或运行时配置变更。
- 首页显式 `agent_ids: []` 不再回退到平台默认类型。类型与主平台需同时匹配现有 Server 的 `assistantCreationIdentity`。
- 首页设置保存时保留兼容的主平台；缺失或不兼容时，按选中且首页支持的类型初始化主平台，并在同一请求保存 `agent_ids`。其他页面的现有设置弹窗行为保持不变。
- 不扩大 Server 支持的创作路线；跨主平台类型及专用类型仍在已有创作页使用。
- 未来审核通过发布只需更新 Studio 镜像；本 PR 不执行合并或部署。发布时继续遵循现有静态资源兼容与回退流程。

## 验证

覆盖空配置、旧平台但显式空类型、平台与类型匹配、公众号文章/贴图切换、保存成功后继续发送与重新进入、取消与失败、专用创作页携带人设 ID；验证结果以 PR 中的实际记录为准。
