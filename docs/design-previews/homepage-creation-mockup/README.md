# 首页效果稿：保留原布局，减少重复人设

这是供视觉确认的独立 HTML 效果稿，不接入业务 API，也不创建真实任务。
基于 `main` 的 `7785e074`，位于 `codex/homepage-creation-mockup` 分支。

## 本轮确认内容

- 保留现有侧栏、顶部人设、中部卡片网格和底部输入框的布局。
- 顶部集中展示当前人设；网格仅展示其他五个可切换人设。
- 去掉输入框上方重复的人设名称和模式提示。
- 将模式提示放在输入框底部、创作类型之前，使用小图标与文字，无底色、边框或阴影。
- 点击「调整人设」切换为「人设模式」，选择人设卡片切换为「创作模式」。
- 人设模式收起创作类型和生成参数，输入提示同步更新；已输入内容保留。
- 将「选择人设」改为「切换人设」，明确卡片用途。
- 切换后，旧人设回到被点击的卡片位置，其他卡片保持原位。
