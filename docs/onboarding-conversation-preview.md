# 对话逐步形成 IP 画像：交互样例

2026-10-09，延续 `feature/project-creator-onboarding` 分支。此轮响应用户对“仍像填表”的反馈。

## 当前可体验的内容

- 初次进入是空白人物轮廓，无默认客户、品牌或已确认信息。人物是抽象视觉符号，不推测真实外貌。
- 左侧自由对话，右侧只读画像。一句话可以同时补充多个维度，无必填字段、步骤编号、完整度百分比。
- 花店经营者为虚构样例，三轮演示身份与读者、语气与边界、平台与本次选题的逐步呈现。另有一轮纠正读者的例子，纠正后必须重新确认。
- 允许“独有经历”暂空，确认条件由外部 `ready` 提供，UI 不按填满六项判断。确认后进入明确标注的创作交接示例，没有创建真实任务。
- 本次创作意向独立展示，不写进长期画像记忆。展示维度不是新的服务端 Schema。
- 未发送文字阻止确认；发送中防重复，失败保留输入；中文输入法确认不误发。清空演示须确认，离开有未保存提醒，没有持久化恢复承诺。

## 预览与真实能力边界

`studio/src/components/projects/PortraitConversation.tsx` 是受控展示组件；`studio/src/dev/PortraitOnboardingPreview.tsx` 是独立演示控制器，没有接入正式路由、API、模型、账号或数据库。演示只对完整匹配的示例回答应用预设结果，任意自由输入不会被伪装成已经分析，更不会被套用为花店信息。自由输入会提示未纳入画像，须显式选择继续示例才能确认示例画像。

本地入口 `studio/tmp/onboarding-preview.html` 继续使用原预览地址，加载上述演示组件。`tmp/` 被忽略，不打包到正式应用。可在该 HTML 的模块脚本中加载以下入口复现：

```tsx
import { createRoot } from 'react-dom/client'
import PortraitOnboardingPreview from '@/dev/PortraitOnboardingPreview'
import '@/index.css'
createRoot(document.getElementById('root')!).render(<PortraitOnboardingPreview />)
```

样例固定轮数仅便于体验，不应移植为正式 AI 的固定提问流程。正式产品须根据对话动态决定追问，可跳过已知信息，允许不知道、纠正和后续补充。正式入口和旧版表单此次不变；不能将这个预览描述为已经上线的真实 AI 新人引导。

## 正式接入路径

沿用 `docs/project-creator.md` 的交互会话方向，不把原 `profile-analysis` 一次性分析伪装成多轮 Agent，也不在浏览器复制执行框架。

1. 先恢复主仓库锁定但当前无法拉取的 harness 提交，再核对正式交互协议与 Agent 资产。
2. 对话消息、结构化画像候选、证据来源和缺失项由真实 Agent 返回。通过适配层转换为 UI 展示数据，保留原六维画像结构；“独有经历”只展示有证据的相关信息，不新建数据库字段。
3. 服务端校验会话归属、草稿与版本。确认必须绑定当前候选版本；纠正后撤销旧确认。业务草稿的持久化、恢复策略应单独审查，不能让前端聊天记录取代服务端事实。
4. 显示用户自述、AI 归纳/推断、已确认等区别；未获得足够信息时不能编造。可创作条件以本次任务必要信息为准，不要求长期画像填满。
5. 确认后把长期画像引用和本次创作要求分别带入现有任务创建链路，沿用权限、计费、快照、生成和发布机制。

本次不修改服务端、数据库、harness、Agent Pack、生产导航或现有表单功能，不合并主分支、不发布。

## 验证结果

前端完整测试 125 个文件、1095 项通过；`bun run build` 通过，保留既有大分包提示。新增 6 项测试覆盖空白起点、多维更新、自由输入不伪归因、纠正后重新确认、未发送文字和失败保留、重复发送及中文输入法边界。浏览器走通三轮示例、纠正、确认、创作交接并恢复空白起点。构建产物中未包含演示故事或页面模块。

## 补充：浏览器语音输入

输入框内新增带文字的麦克风按钮，调用浏览器 `SpeechRecognition` / `webkitSpeechRecognition`，默认中文。只有点击才启动，不预先请求麦克风；识别期间可停止，停止后检查、编辑文字并手动发送。原输入保留，临时识别结果更新不会重复追加；录音期间禁止发送、确认画像和用示例覆盖文字。组件卸载会终止识别；服务未返回结束事件时有退出兜底。

语音转文字是真实浏览器能力，画像对话仍是预设演示。浏览器可能通过远端语音服务处理音频，页面已提示，并不承诺离线识别。API 存在也不代表识别服务一定可用；权限拒绝、无麦克风、无语音、网络或服务不可用均有提示，保留现有文字，可改用系统/输入法的语音输入。

浏览器检查确认当前内置浏览器暴露该接口、按钮与提示正常显示；未替用户启动麦克风，真实语音识别成功仍待用户试说验证。自动化测试使用模拟识别事件，覆盖转写追加与修正、不自动发送、权限失败、前缀接口、不支持、卸载释放及停止超时。

接口依据：[SpeechRecognition](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition)、[stop](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition/stop)。
