# 小红书图片内容规划步骤设计文档

**日期**：2026-03-17
**状态**：待实现
**影响文件**：`agents/rednote.md`

---

## 问题描述

小红书创作流程中，图片生成直接依赖文案正文（`content.md`）作为内容来源。由于小红书文案设计上就是简洁对话式的（三段式：开头钩子 + 2-3 段正文 + CTA），导致：

1. **情感/体验类笔记**：文案是情绪化种草，图片却无实质内容可展示
2. **知识/干货类笔记**：文案写得简洁，图片内容也跟着稀薄，无法达到"每页 2-4 个结构化信息点"的标准

根本原因：文案（供阅读，简洁对话式）和图片内容（供视觉呈现，高密度结构化）服务不同目的，却共用同一份内容来源。

---

## 解决方案

在步骤 4（创作内容）和步骤 5（生成图片）之间，插入**步骤 4.5：图片内容规划**。

Agent 基于主题、标题、目标受众**独立规划**每张图的具体内容，写入 `$DIR/image-plan.md`。图片生成时使用 image-plan.md 的内容，而非文案正文。

---

## 流程变更

### 原流程

```
步骤4 创作内容(content.md) → 步骤5 生成图片（{page_content} = 文案正文片段）
```

### 新流程

```
步骤4 创作内容(content.md)
  ↓
步骤4.5 图片内容规划(image-plan.md)
  - 输入：主题 + 标题 + 目标受众 + 文案正文（参考语气，非内容来源）
  - 输出：每页具体知识内容（主题 + 2-4 个信息点 + 推荐布局）
  ↓
步骤5 生成图片（{page_content} = image-plan.md 对应页内容）
```

## image-plan.md 规范

### 文件结构

```markdown
# 图片内容规划

## 总体策略
- 主题方向: xxx
- 目标受众: xxx
- 图片内容定位: xxx（如：从情感种草扩展到实用干货，增加收藏价值）
- 计划图片数量: N 张（奇数，推荐5-7张）

---

## cover 封面
- 钩子: （≤10字，吸引点击的一句话）
- 辅助信息: （1个数字或悬念，≤15字）

---

## image_02 [内容] 主题：xxx
- 信息点1: （具体内容，20-60字，含数字/场景/细节）
- 信息点2: （具体内容）
- 信息点3: （具体内容）
- 推荐布局: 编号清单 / 对比双栏 / 步骤流程 / 标注图解

---

## image_03 [内容] 主题：xxx
...

---

## image_0N [尾部]
- 总结条目1: （核心 takeaway）
- 总结条目2:
- 总结条目3:
- 一句话核心观点: （全文最重要的结论）
```

### 信息点丰富度标准

每个信息点必须是**可以直接放进图片的完整内容**，而非概念标题。

| 质量等级 | 示例 |
|---------|------|
| ❌ 差（概念词） | "介绍咖啡馆选择技巧" |
| ✅ 好（具体内容） | "🔍 看评分：大众点评≥4.5，且近30天有评价（排除刷分店）" |
| ❌ 差（泛化描述） | "附近有很多选择" |
| ✅ 好（含数据） | "深圳福田区：人均50-80的精品咖啡馆超过200家，值得打卡的不到30家" |
| ❌ 差（模糊步骤） | "第一步做准备" |
| ✅ 好（可执行步骤） | "Step1 出发前：查小红书「城市名+咖啡」，按收藏量排序，筛出收藏>500的" |

**字数要求**：每个信息点 **20-60字**，包含具体数字、场景或可操作细节。

### 规划原则

- **情感类主题必须知识化**：把情感体验转化为可复用干货（打卡体验 → 选址技巧；旅行感受 → 行程攻略）
- **每张图主题不重叠**：内容图之间信息点不交叉
- **信息点独立于文案**：不依赖文案正文的叙述，基于主题和目标受众独立推导

## 修改范围

### 1. `agents/rednote.md`

#### 原创模式

在步骤 4 和步骤 5 之间插入：

> **步骤 4.5 — 图片内容规划**：基于选题方向、最终标题和目标受众，独立规划每张图的具体内容。规划时不依赖文案正文的叙述，而是围绕主题自主展开知识内容。每个信息点 20-60 字，包含具体数字/场景/可操作细节。情感类主题须知识化扩展（将体验转化为干货）。结果保存到 `$DIR/image-plan.md`。

步骤 5 说明更新：图片生成时，每页 `{page_content}` 使用 `image-plan.md` 对应页的内容，而非 `content.md` 正文。

#### 复刻模式

同样在步骤 5 和步骤 6 之间插入步骤 5.5，规划逻辑相同，但需参考源笔记的内容结构。

---

## 成功标准

- 生成的图片每页包含 2-4 个具体、可操作的信息点
- 情感/体验类笔记的图片能展示相关知识干货，不再只是情绪描述
- `image-plan.md` 可作为独立产物审查，信息点具体程度达到"20-60字含数字/细节"标准
- 图片内容与 image-plan.md 规划内容高度一致（AI 忠实渲染，不需要自行发挥）
