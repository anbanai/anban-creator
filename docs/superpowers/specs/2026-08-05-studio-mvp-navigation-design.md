# Studio MVP 导航精简设计

## 目标

Studio 侧边栏只呈现 MVP 的核心工作路径，移除“创作”“自动化”“经营”等不提供操作价值的分组标题，降低导航噪音。

## 导航结构

普通用户按以下顺序看到一个扁平导航列表：

1. AI助手
2. 项目
3. 任务
4. 计划
5. 钱包

“时间轴”和“用量”不再出现在侧边栏或命令面板的主导航结果中，但保留现有路由与页面，确保已有直达链接继续可用。本次不改变 Server API、权限、数据模型或页面业务行为。

管理员继续拥有“设计师”“模板库”“Claude Code”“Codex”“设置”等内部入口。这些入口排列在 MVP 导航之后，通过视觉分隔线与普通用户入口区分，但不显示新的分类标题。管理员路由保护保持不变。

## 组件边界

`studio/src/lib/navigation.ts` 提供明确的 MVP 导航项与管理员导航项，供侧边栏、命令面板和快捷入口复用。隐藏的“时间轴”“用量”不再属于全局导航集合。

`studio/src/components/layout/Sidebar.tsx` 直接渲染扁平列表，不再渲染带标题和图标的分组组件。移动端关闭、折叠态 Tooltip、活动路由状态和搜索入口行为保持不变。

## 测试与验收

- 导航单元测试断言 MVP 项顺序为“AI助手、项目、任务、计划、钱包”。
- 普通用户侧边栏不显示分组标题、“时间轴”“用量”或管理员入口。
- 管理员侧边栏仍显示所有内部入口，并且路由权限测试保持通过。
- 折叠态、移动端导航关闭和命令面板导航继续工作。
- 运行完整 Studio 测试与生产构建。
- 在桌面和移动视口检查导航无溢出、重叠或空分组。

## 非目标

- 不删除“时间轴”或“用量”的页面、路由、API 与业务代码。
- 不调整首页、项目、任务、计划或钱包页面内容。
- 不改变管理员权限模型。
