# 参考视频与口播 Montage 成片对比报告

评估日期：2026-11-04。对象：茶叶分类参考、荷花名称参考，以及用户指定的《筷子》成片 `final_副本.mp4`。

**当前最值得修的不是素材数量，而是画面的解释能力。** 两条参考片都把“对象发生变化”组织成内容：茶叶的处理与状态对应分类，荷的生长状态对应名称与诗句。我们的成片已经有生成镜头、图形、字幕、配乐和人物小窗，但部分镜头只与名词相关，没有在口播需要时完成比较或动作演示；还存在文字压脸、标签尺度偏小、话题切换后旧元素滞留的问题。增加生成次数或继续堆规则，不能自动解决这些缺口。

本次完成的是有证据的制作诊断与 Agent/Skill 修订，**尚未产出并验证一条新版终片，不能宣称已达到参考品质**。达到标准的判据见后文；播放量更不能由改提示词保证。

## 1. 证据范围与测量

三条源文件只读，记录 SHA-256；ffprobe 探测完整媒体，FFmpeg 每 2 秒等比例抽帧、全轨响度测量；本地已缓存的 faster-whisper small（CPU int8、中文、VAD、词时间戳）生成完整音轨的机器转录。共检查茶叶 26 帧、荷花 58 帧、成片 71 帧及其联系表。完整证据索引见 [evidence/manifest.json](talking-head-montage-review-evidence/manifest.json)。

**限制：本轮是全时长覆盖的抽帧分析、机器转录和技术测量，未完成正常速度连续观看/逐帧动作审核，也未完成全片人工听检。** 下文时间码约到秒，是定位窗口，不是帧精确切点。ASR 含“七情/杠杆/大禹/殷墟”等同音词错误，不是校对后的台词，不据此判定音频真的念错或出现重复。节奏顺滑度、音乐衔接、口型、手部运动真实性仍须连续审片确认。

## 2. 茶叶参考：以稳定比较轴解释分类

| 约略窗口 | 可见表达 | 制作价值与需注意处 |
|---|---|---|
| 0–10 秒 | 同一类叶片形象，局部示意，绿色状态与绿茶名对应 | 主体明确；先呈现处理/状态再给分类名。分子图只能作示意，不能凭图认定科学准确 |
| 10–18.5 秒 | 水分/叶片外观变化，白茶名与代表茶信息 | 沿同一比较轴推进，观众不用重新找主体 |
| 18.5–26.4 秒 | 叶片变黄，黄茶分类 | 颜色承担解释，分类标签是结果而非全部信息 |
| 26.4–35.7 秒 | 叶缘与中部外观差异，乌龙分类 | 局部差异可用于比较；具体氧化程度不能仅由图推断 |
| 35.7–45.2 秒 | 揉捻/破碎示意，叶片状态转向红褐 | 动作与结果有视觉对应，优于只放红茶杯 |
| 45.2–51.5 秒 | 后续处理及黑茶类别 | 分类链收尾；是否过度简化工艺待领域核验 |

## 4. 我们的成片：具体问题和修法

| 位置 | 已观察证据 | 编辑判断 | 优先修法 |
|---|---|---|---|
| 0–7 秒 | 开场转录提出外国人为何练不好筷子，随即诉诸处世哲学 | 技能因果问题与文化寓意之间缺少论证桥梁；不是靠特效可弥补 | 从原始 take 选可被后文兑现的开场；以文化解读为主题时不能承诺解释人群技能差异 |
| 8–14 秒 | 尺寸/七寸六分图形位于人物上方，字号偏小 | 信息可以辨认，但在整幅竖屏中权重低；“统一尺寸”和“七情六欲起源”另需证据 | 真实物件近景与尺寸关系；未核验内容改为有出处的民俗说法或删去，不把寓意剪成统一规格 |
| 16–32 秒 | 七情网格占据暗背景；口播已进入节制/分寸时网格仍保留 | 画面与主题相关，却不再推进正在讲的这一句 | 比较/分类段结束让列表退出；只保留对当前解释有用的两端关系，或回真人 |
| 34–52 秒 | 筷子近景后出现独立“方”框及圆碗/圆的叠加 | 关键词视觉化多于对象结构解释；碗的圆不能代替筷子截面 | 用同一根筷子的顶部/底部和截面，标签靠近对应位置；文化象征单独标明 |
| 54–60 秒 | “试试看”“两根都动”对应的是放在桌面的筷子 | 关键动作没有在需要的位置呈现，是最值得先修的镜头任务 | 提前进入握持近景，呈现可比较动作；没有可用原片则补拍/生成并严格审核 |
| 62–68 秒 | 手持筷子、米饭及黄色示意线，有夹起的结果帧 | 已有演示意图，不能说整片全是静态；线条与真实动作是否一致尚未连续核验 | 连续看握法、接触、相对运动和夹起结果；只看起止帧或箭头不算通过 |
| 70–90 秒 | 古人煮食、考古式铜筷画面，带“AI生成画面”标记 | 标记值得保留，但图像无法证明大禹传说、具体墓号与年代 | 传说加限定；考古主张核原报告/馆藏，生成图仅作示意，避免冒充现场证据 |
| 92–106 秒 | 龙/凤字卡、焚香、指人/插筷示意 | 寓意和礼仪连续增加，初始问题仍未被回答 | 围绕主线取舍；每项礼仪给明确行为与含义，避免再开不必要的分支 |
| 114–122 秒 | 累积列表逐渐压到人物额头、眼睛和脸上 | 可直接确认的排版缺陷，不是审美偏好 | 限制列表可见项、移到真实空区或独立画面；检查整个出现/退出过程及脸部运动 |
| 124–140 秒 | 端碗、筷子和餐桌收尾 | 能服务家风主题，较难兑现“为何外国人练不好” | 结尾回扣选定的文化主张或握持机制；不能把二者混为一条因果 |

此外，多处整幅暗化、小人物圆窗、微小标签与较长字幕行共同争夺画面空间。编辑建议是让解释对象承担主画面，按需要切回真人；局部底条/描边和布局调整优先于整体压暗。不应把“每段都有小窗”误当身份连续性的必要条件。字幕的准确断句和特殊词校对必须回听原音，本轮不把机器误识别直接算成成片字幕错误。

### 综合比较与根因置信度

| 维度 | 茶叶/荷花参考 | 当前成片 | 结论强度 |
|---|---|---|---|
| 主线 | 分类轴 / 生长状态与名称 | 技能问题 → 哲学 → 尺寸 → 历史 → 礼仪 → 家风 | 抽帧与转录支持主题跨度较大；并不意味着多主题必然差 |
| 画面解释 | 状态差异/变化有明显所指 | 部分动作段用静物，部分结构段用关键词 | 有明确窗口证据，优先修 |
| 连续性 | 共享叶片/池塘视觉系统 | 真人、暗卡、古人、考古、饭桌频繁切换 | 视觉风格与对象连续性较弱；转场流畅程度未测 |
| 可读与遮挡 | 大主体、名称邻近对象 | 小标签、长行、列表压脸 | 压脸可确认；手机实际可读仍需设备测试 |
| 声音/传播 | 有客观测量，无后台 | 有客观测量，无后台 | 不作音质排名或播放归因 |

**已经确认的是成片缺陷，尚未确认的是导致它的具体执行步骤。** 旧 Agent/Skill 已经写过头部零遮挡、语义解释和独立审核，因此不能简单归咎“缺少这些规则”。更合理的待检假设是：主观验收没有绑定实际终片；计划里写“演示”但生成结果只做了主题匹配；审批被文件齐全或技术通过替代；重复且分散的业务指令削弱了优先级。这些假设需要同一候选的 EDL、生成记录、审查记录和 revision 链证实。

本机另有同题 OpenMontage 输出，但其中策略记载约 153.9 秒/rev-005，与用户成片 142.4 秒不符，相关媒体哈希也不相同。**不将这些日志或 EDL 认作本成片的执行证据。** 本次未取得与用户文件绑定的原始口播和 EDL，因此不能诊断某次模型调用、剪辑源码或音频拼接是否是根因。

## 5. 顶尖团队会额外做的工作与原始材料

以下是面向本任务建议采用的专业工作方式，不是对所有专家行为的调查结论。

| 超出“分析参考、改提示词”的工作 | 最原始输入 | 具体产出/作用 |
|---|---|---|
| 先核选题与承诺 | 未剪完整 take、原始提纲、目标观众真实问题 | 找可兑现的 Hook；区分已有原话与需要补录的新话 |
| 重建事实来源 | 考古原报告/馆藏记录、工艺资料、植物学资料、原诗文 | 核主张、限定、历史/传说/寓意边界；参考视频不是来源终点 |
| 做物理动作测试 | 手、筷子、被夹物实物及完整近景 take | 先确认怎样演示才看得懂，再决定是否用 AI 重现 |
| 设计可连贯生成的镜头 | 原始参考母版、关键帧、对象视角与空间布局 | 固定对象身份与状态，避免每段重新随机创造世界 |
| 先验证最难的一段 | 原声、低成本预演、代表性生成样片 | 把钱花在验证解释方法上，再扩展到全片 |
| 分离制作判断与传播判断 | 原生后台导出、曝光/流量来源、留存曲线、评论原文 | 检查为什么某处掉人；不把热门样本与制作因果混为一谈 |
| 独立验收 | 当前终片文件与哈希、匿名化评审版本、真实受众反馈 | 防止制作者按自己的意图替画面解释 |

相机卡完整视频、独立麦克风原轨、room tone 与原始时间码还可判断错误是否来自收音/源片，而不是成片混音。整理后的摘要、ASR、自动分镜、EDL 和 AI 自评分只能帮助定位，不能取代原件。本轮真正拿到的是三条成品媒体；缺失项已保留，不假造补齐。

## 6. 具体方法、工具与一段可执行重做方案

工具按用途分工：ffprobe 核流/帧率/时长；FFmpeg 抽帧、解码、测响度与准备对照片段；当前 OpenMontage registry/native hybrid pipeline 做正式生成、转录和渲染；现有 composition/generated-video/render-QC 脚本验证时间线、资产与最终音轨。外部原文检索核事实，播放器/手机检查实际观看，未参与制作的审核者和真实观众检验结果。**本轮用于研究的本地 Whisper 不被新增为生产工作流的另一套转写依赖。**

本轮采用和建议延续的方法：

1. **声画逐句对照**：每句指出观众此刻应该看见什么。名词匹配不够，动作句必须有动作/结果。
2. **对象状态分镜**：记录对象、起态、动作、终态、连续性；同一对象跨镜头先锁关键帧，再生成运动。
3. **主张与证据分层**：机制由演示/资料支持，史实由原始来源支持，寓意以文化解释呈现。
4. **代表样片先行**：挑最难解释单元及前后衔接，检查通过后再扩展；不是随便生成最漂亮的一段。
5. **等条件比较**：同等显示尺寸、响度、观看次数；参考和候选按相同解释目标审，不按固定切镜数审。

以当前 54–68 秒筷子片段为首个重做目标，建议如下。时间是样片内相对位置，属待试方案，不是通用模板或强制时长：

| 样片阶段 | 画面任务 | 成功可观察条件 |
|---|---|---|
| 进入（约 0–2 秒） | 从真人判断切入同一双筷子、手和可夹物，给清楚的握持视角 | 手指与两根筷子关系完整，无遮挡，观众知道哪个对象要动 |
| 对照（约 2–6 秒） | 在来源支持的前提下展示相对运动差异；不为了“失败示范”制造错误物理 | 观众能指出两种状态差别；标记跟随真实对象，不悬空 |
| 动作（约 6–10 秒） | 接触→合拢→夹起，连续保留结果 | 物体不穿模、不突然生成；动作与当前口播锚点对应 |
| 退出（约 10–14 秒） | 若原话转入一主一辅/阴阳比喻，保留动作结果再揭示文化解释 | 物理演示与文化比喻分清；字幕和标签不代替动作 |

原始音频不支持这种连续结构时，改选可实现的段落或提出补录需求，不能合成真人未说过的新台词。手部生成反复失败，应改镜头/取得可用演示素材；流程仍保留核心 AI 视频要求，可让经审核的 AI 镜头承担另一项合适的核心解释，不能静态替代后宣布通过。

整片建议先选定“筷子的文化寓意与礼仪”或“筷子的握持与相对运动”之一作为主线；选择应以原始 take 和事实核验为依据。当前素材更偏文化解读，但在未拿到完整源片前，不预先指定新 Hook 台词或不可逆删段。

## 7. 除了你我，什么能证明结果正确

正确不是一个总分，至少需要分开判断：

| 验证 | 提供者/工具 | 能证明什么 | 本轮状态 |
|---|---|---|---|
| 文件与媒体事实 | SHA-256、ffprobe、FFmpeg | 同一个文件、编码/流/响度等可复算事实 | 已执行，证据随报告保存 |
| 时间线、资产采用、最终音轨 | 现有 QC + 同 revision EDL/音轨 | 时间映射与证据一致性；不自动证明美感/真实动作 | 缺该成片绑定 EDL，未执行生产验收 |
| 事实正确 | 原始出处及具备相关知识的领域审核者 | 主张与限定有依据，示意不冒充证据 | 未完成领域审核 |
| 制作品质 | 未参与该 revision 制作的剪辑/视听审核者 | 全速连贯、动作可辨、文字可读、声音与口型无明显缺陷 | 尚无独立完整媒体审片 |
| 观众理解 | 目标观众一次观看后的自由复述/操作任务 | 看懂主张、关系和动作，而非“感觉不错” | 未招募、未执行 |
| 传播改进 | Server 冻结的同口径 analytics 与明确对照 | 支持表现变化判断；因果仍依赖实验设计 | 无后台/对照，未验证 |

建议首次小样用一个小规模真实观众试测发现问题，例如 6–10 名目标用户（仅为可行试测规模，不是统计充分性标准）。先固定“看完应能回答什么”，随机安排参考/候选顺序或使用不同受试者，避免第二次观看的学习效应；不告知哪版是自己的，不提前解释画面。让观众复述、指出哪根筷子怎样动、区分示意与史实，记录原话和错误类型。小样结果可指导返修，不能推广成平台增长结论。

参考对标在开工时只选择本题的少量关键维度：承诺兑现、核心动作/状态可辨、对象连续、文字与所指同步、小屏可读及完整视听体验。每项记录参考时间码、候选时间码、方法和“更差/相当/更好/未测”。**核心解释缺口、误导性主张、脸部遮挡不允许被美术平均分抵消；关键项未测不算达标。** 最终候选需独立完整审片和全片听检，绑定 SHA-256；修改后重验受影响项目。
